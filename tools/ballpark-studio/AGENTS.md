# 球場設計室の描画方針

2026-10-25: 球場デザインは本人が完成確認済み。芝生ロゴの採用明るさ0.8倍。最新状態は [CURRENT-accepted.md](../../docs/ballpark-studio/CURRENT-accepted.md)。保存済みの利用者設定を自動上書きしない。

2026-10-24 本人の追加指示。専用tools/ballpark-studioに適用する。

- ロゴだけを線や精密pixelで上書きしない。素材を地面の色へ合成した後に光点へ変換する。
- 細部が必要な場合は、ロゴと周囲の芝生を含む局所領域の光点密度を上げる。領域の外縁は滑らかに移行させる。
- 追加指示: 広い矩形の高密度領域も本人が違和感として指摘。画像の可視マスクに沿い、輪郭から最小限の余白だけを細分化する。未指定時は余白0.6m・移行0.8m。芝生も同じ光点方式で、細かな領域をロゴ全体の外接矩形へ無条件に広げない。
- 密度の領域・倍率・余白・移行幅を人間とAIが同じ設定/inspectで扱えるようにする。他の素材でもこの経路を再利用する。
- 読み込む狼素材は、最後に本人が示した完全な金色狼の参照を画像加工したものを使用。本人が拒否した手描きの代替輪郭へ戻さない。
- 元の投影・光点・深度・PNG・内野の配置・Core物理/裁定を保持する。局所密度は表示の設定であり物理の精度や判定を変更しない。
- この領域は他chatのsrc/dist/メーカー/V115 CURRENTを所有しない。専用docsの継続記録と実検証receiptを使い、他taskを上書きしない。
- 観客はチーム色LEDの2/3コマ。通常約400ms、安打等は短い間隔で振る。描画は観察のみで公式の安打/失策/OUTを決めない。イベントIDを重複再生しない。
- 静止した設計室は最大3枚のscene画像を再利用し、コマ切替で世界全体を再計算しない。停止/非表示/旧球場でtimerを止め、reduced-motionを尊重する。通常試合に静止scene cacheを流用して選手や球を止めない。試合へはcrowd clock/symbolのread-only経路を接続し、動的worldは通常どおり描画する。
- 最新指定: ロゴ細分は2〜8倍、明るさ/光り方を設定可能。発光も元の光点に適用し、ロゴ専用の線overlayを作らない。
- 観客は初期25%/簡素表示。表示密度・描き込み・身体サイズ・LED明るさを調整可能にする。身体/腕の動きとLEDの実寸は別にし、棒の長さは常に0.07m。遠景で見せるために長い棒へ伸ばさず光点で表す。
- 本人のループ指定は「2コマ動作を2周→3コマ動作を1周」で計7コマ。左右→左右→左中右（0,2,0,2,0,1,2）。各コマを2・2・3拍保持する意味にはしない。
- 最新指定は観客を塊にする方式。スタンドの全quadへ共有3コマの群衆タイルを敷き、個別観客の位置生成/描画へ戻さない。旧crowdSymbol/includeCrowdは互換参照で、現行rendererから呼ばない。LED密度を下げても群衆背景を消さず満員の模様を保つ。通路/手すり/屋根は既存の深度で維持。
- ペンライトにはnative光点の発光を適用する。タイルの発光島は複数の短いLEDの集まりで、1本を長く引き伸ばした表現ではない。明るさと光り方を別設定で扱う。ロゴは本人が満足と明示したので変更せず、観客OFF時の旧HTML画素一致とロゴ領域の画素一致で保護する。
- 本人が群衆タイルの見た目を承認した後、無観客/満員の切替を指定。無観客は元の座席materialを表示し、群衆/LED/animationを止める。optionalなcrowd.attendance=full/emptyを保存/履歴で扱う。欠落はfullで自動追記しない。LED密度と入場状態を混同しない。

- 最新の本人指定により、外装/客席/屋根は世界座標でつなぐ構造にする。壁面の狼にも芝生の採用PNGを素材合成してから同じdotで描く。看板面の局所細分は周囲の下地も含める。芝生の輪郭距離マスク/数式/素材画素は維持する。外装の繊細な模様もUV素材経路を使う。細分点は投影三角形と共有world depthで遮蔽する。詳細はREADME-architecture/CURRENT-architecture。
- 建築形状の変更に伴い、旧HTMLとの全景画素一致は要求しない。承認済み芝生の比較領域、元rendererの基準画素、固定内野、同一rendererの空席material経路は一致を検証する。旧FAIL/旧全景一致の証跡は履歴として保持する。

- 遠景の素材は座標投影だけでなく、投影サイズ/傾き/深度に応じたsample・局所密度・強調で評価する。画像を原解像度の最近傍で常に精密表示しない。壁面にはmipmap/LODを使い、ロゴと周囲の下地を同じ格子にする。芝生の既存sampleは別経路として保護。
- 現在のLOD/深度contrast係数は暫定の美術調整で、唯一の正解や実測の物理定数ではない。近遠/全視点の比較画像と負荷を確認して見直してよい。技術PASSだけで見た目の完成・人間承認を宣言しない。

- 2026-10-24最新: 本人が壁面ロゴの減光を強過ぎると指摘。距離によるcontrast/opacity低下をやめ、目立つ形/明るさを維持し細部が少しぼやける程度にする。旧の深度減光の記述は履歴で、現行指示として再導入しない。
- 中央スコアボードは承認済み画像の上部狼/横長表示/赤青金の枠を共通world構造で作る。文字も素材→局所光点→共有深度。表示見本と公式成績を区別し、Rは各回から集計する。見本編集/保存/取消、ロゴと表示盤の独立toggle、9視点と屋根内収容を検証。README-scoreboard/CURRENT-scoreboardを参照。
