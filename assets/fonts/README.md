# Review font

Noto Sans JP, SIL Open Font License 1.1 (`OFL.txt`).

`NotoSansJP-review.woff` is a subset of the variable font from:
https://raw.githubusercontent.com/google/fonts/main/ofl/notosansjp/NotoSansJP%5Bwght%5D.ttf

Fetched 2026-10-01. Subset with fontTools using the Japanese/Latin text in
`scripts/pixel-preview.mjs` and `tools/pixel-player/authoring.ts`.
The checked-in WOFF is embedded into review HTML, allowing offline Japanese
labels without depending on the host's installed fonts.
