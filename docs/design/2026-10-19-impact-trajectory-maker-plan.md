# 俯瞰倍率の訂正と弾道・選手メーカーの試験計画

状態: 人間が選択肢1（全候補検証＋通常試合接続）を明示承認。追加要求は分かりやすい言葉、マウス約1秒で詳説、スマホは説明ボタン。既存20選手を一括変更せず実装を進める。

## 1. 俯瞰の表示倍率

- 前回の「地面からの拡大差」ではなく、その高さの球の基準表示自体へ倍率を掛ける。
- 空中球の倍率を2へ。地面の従来サイズと保持球非表示は維持する。
- 同じカメラ・同じx/zにある地面球の表示を基準に、実際の光学投影の比を掛け、その大きさをさらに2倍にする。最小白点に遠近差を消されないようにする。
- 接地の境界だけは球1個分の高さの範囲で連続につなぐ。高さ2mならこの接地緩和は終わっており、指定倍率がそのまま適用される。
- 例: 地面10px／その高さでの基準12pxなら、設定2で24px。地面は10pxのまま。
- 1は従来表示に戻す互換設定。今回の依頼に従い新HTMLの初期値は2。通常全体倍率とは独立する。
- 俯瞰以外、球の物理、接触、速度、回転、AI、裁定、打者v66の微動・走者追尾は変更しない。

## 2. 実測フォームの事実と選択範囲

- 出典: OpenBiomechanics pinned commit `44b98dae05cceb016f080ab39d105c85b8639084`、`dataset-v1`。
- 索引677試行・98人。現実装の再生可能軌道は12本（左右各6本）。
- 原CSV監査では673試行が既存の欠損・接触窓・手元残差条件を満たす。4試行の欠損5行を補完しない。
- 全673試行を対象にする場合、さらに全剛体姿勢・時刻・左右・速度・Coreの検証を通してから候補へ出す。これを600人分の固有フォームとは呼ばない。
- サイズを抑える実行用表現と、原データ・SHA・元行索引の検証記録を分ける。原CSV・既存12本は保全する。
- 左右で絞り込み、選手ごとに既存の `physical.clipId` でフォームを選ぶ。勝手な左右ミラーやMMDへの復帰は行わない。

## 3. 弾道の試験設定

- 弾道1〜4を選択し、試験初期値は2＝元の軌道。角度の初期差は1:-10度、2:0度、3:+10度、4:+20度とする。
- この段階対応は作者による研究用初期値で、実測済みの弾道分類とは扱わない。比較欄で角度差を編集して目視確認できるようにする。
- インパクト前100ms〜後60msを初期の調整区間とする。区間外は元の標本時刻・位置・姿勢を保持する。
- 実測の接触芯位置を支点に、グリップとバット姿勢を同じ回転で変形する。接触位置と剛体長を保持し、区間端の変位・速度・加速度が連続につながる重みを使う。
- 既存の全区間 `attackAngleDegrees` は互換用に残し、新しい局所調整を省略したJSONでは旧挙動を保持する。
- 同じ調整済み軌道をCoreの衝突と描画へ渡す。変形後の速度上限も計算し、選手の能力上限を守る。打球の角度・回転・結果を弾道タグから直接決めない。

## 4. 比較・保存・通常試合

- 既存メーカーの選手作成／軌道調整の2切替を維持する。
- 選手とフォームを選び、同じ入力投球・同じ時刻で元軌道と弾道1〜4の違いを比較する。
- スロー・一時停止・インパクトへの移動・複数方向の比較を再利用し、元軌道と変形後の芯の道筋・インパクト近辺の進行角を確認できるようにする。
- 選手別フォーム・弾道設定・比較用調整値をJSONへ保存し再読できるようにする。
- 初期20選手の能力やフォームを一括で変更しない。通常試合への接続を今回含める場合も、編集・読込した設定だけを適用する。

## 5. 明るいメーカーとG〜S表示

- メーカーは明るい背景・暗い文字・十分なコントラストへ変更する。試合の粗い画質やカメラ構図は変更しない。
- 公開0〜100能力には正式設計のG〜Sを表示する。S90〜100、A80〜89、B70〜79、C60〜69、D50〜59、E40〜49、F20〜39、G0〜19。
- 主表示はランク、精密な編集値は入力欄／詳細で扱う。球速km/hや秒・m等の実単位は数値を維持する。
- 選球眼の絶対1〜100と、他能力のリーグ比較を混同しない。新しい眼球能力等は追加しない。
- 出典: `09-player-trait-catalog.md` canonical ref `63ccf99e29dba0488278f52db39747c68e07b545` §2。

## 6. 検証

- 俯瞰: 地面不変、高さ2mで基準球径×2、物理／他視点／保持球非表示、保存・再読。
- 変形: 区間外の元姿勢一致、調整0の互換一致、接触芯・剛体長・左右・時刻・境界連続性、速度上限と同一衝突／描画。
- メーカー: 選手別保存、弾道・フォーム切替、G〜S全境界、選球眼絶対値、明るい配色、PC／390px幅、旧新JSON。
- Core: 型検査と関連テスト。通常試合へ接続する場合は同一初期設定の比較と9回完走を行う。
- 原FAIL／UNKNOWN／Charter未承認HOLD、v66の既存分数時刻角速度超過と、元の全計画の未達を保持する。新しい機能の試験を全計画完了とは呼ばない。
