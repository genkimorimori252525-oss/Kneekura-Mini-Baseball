# v88 — 見送り時間と空振りの終端

人間の直接依頼：HR見送りを固定1750msでなく1500〜2000msの抽選にする。確信HRは投手視点のまま見送る。空振りは途中停止せず振り切る。ハーフスイングの発生・個人差・必要能力の研究はLunaを使う。

## 変更の境界

- 見送りは表示専用。投球seed・投球IDに由来する安定した抽選で、同一リプレー・逆seek・カメラ変更で時間を再抽選しない。既に守備へ移ったならその守備者、確信HRで投手に留まったなら投手を保つ。観測済みのフェンス越えから開始し、ボールの物理・得点・走者を変更しない。
- 空振りは実測軌道があるのに、投球の捕球成立で保存frameが終わり、表示が最後のbatで固定されていた。登録済みの運動descriptorから、公式裁定後の表示待機でも同じ実測運動を観測する。実測clipの全フレームを各投球へ複製せず、出典と変換・選択範囲だけ保存する。
- 公式endedAtTick・Sourceのボール・走者・次球開始tick・第三アウト即benchは延ばさない。有限実測終端を超える軌道を創作せず、終端を一度描いて既存の身体フォロー待機を終える。見逃し・接触・バントは従来の表示契約を維持する。
- ハーフスイングを今回の不具合に後付けしない。研究の結論と将来の状態モデル案を分け、新しい公開能力や裁定方式をこの修正で追加しない。

## 研究

調査担当はユーザー指定の **Luna (`gpt-6-luna`)**。`docs/research/2026-10-21-check-swing-v88.md`。

ミートと停止能力の直接対応は確認できない。既存の選球眼を予測の更新・変更判断、積極性を判断閾値、既存のタイミングと実バット速度/慣性を停止可能な残時間の入力に使う案が最小。これらはゲーム上の近似で、MLB選手別成功率に校正した式ではない。独立内部値は、既存入力で説明できない持続的な個人差が必要になった段階で検討する。公開能力を増やす根拠にはしない。
