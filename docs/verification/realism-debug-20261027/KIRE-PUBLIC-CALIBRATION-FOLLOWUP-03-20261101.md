## 1. 森山ほか（2022）

[東海大学の公開本文、pp.29–33](https://www.u-tokai.ac.jp/uploads/sites/11/2022/10/c617f883d07e058a61348cbe8e694494.pdf) / DOI 10.18995/24343633.62-1.29。

**確認できたこと:** 実投球のストレート・カーブ10球を2000 fpsのカメラで解析。別の支持球による風洞測定は40 m/s、1500–3000 rpm、1000 Hzで2秒の収録を5回行い平均と誤差を求める。本文中の揚力・抗力係数は無次元。スライダーの軌道は風洞係数を用いたシミュレーションであり、同一自由飛行球の直接測定ではない。

**未確認・不足:** 機械可読の生データ、材料姿勢と力の位相同期、実投球と風洞力の同一trial対応、データ利用条件。風洞測定の記述から、投球時の相対風と3D姿勢・位置・横力の同期rawを得たとは判断できない。公開PDFとrawの利用許諾は別。

## 2. 村田ほか（2021）

[日本機械学会の要旨・書誌](https://www.jstage.jst.go.jp/article/jsmeshd/2021/0/2021_B-6-4/_article/-char/en) / DOI 10.1299/jsmeshd.2021.B-6-4。

**確認できたこと:** 要旨は大学野球部12人の投球、IoT球による速度・回転数・回転軸の傾き、高速度撮影、1/2/4-seamの流体力実験を記載する。公開ページ上の補足資料は0件で、本文はアクセス制限あり。

**未確認・不足:** 実データの公開先、通常回転範囲、測定の単位、3D材料姿勢・相対風、センサーと動画・力の同期精度、データ利用条件。要旨だけでは同一trialの同期rawや独立横力を確認できず、アクセス制限を回避していない。

## 3. 溝田ほか（2007）

[日本機械学会の書誌・公開論文](https://www.jstage.jst.go.jp/article/kikaib1979/73/734/73_734_1987/_article) / DOI 10.1299/kikaib.73.1987。

**確認できたこと:** 高回転球の回転軸を一様流と平行にした風洞実験で空気力を測定し、姿勢条件による抵抗の違いを報告する。論文PDFは公開されている。

**未確認・不足:** 今回確認した公開書誌・本文から機械可読rawの公開を確認できていない。具体的な回転条件、時刻と材料姿勢の同期、データ利用条件は未確認。特定軸の風洞条件を任意のslider/splitterに一般化しない。

## 次の必要条件

三件とも、通常回転域の同一trialについて材料姿勢・3D角速度・相対風と時刻別位置/速度または横力が同期された再利用可能rawは確認できていない。新たな適合データが見つかった場合は、trial ID・座標系・単位・clock/位相同期・不確かさ・球種/回転域・利用条件を確認してから、固定release条件の独立比較を設計する。本文の図や風洞平均を同一投球の時系列力に読み替えず、仮係数・時間切替・旧V177低回転置換を採用しない。3段階物理は引き続き未完成。
