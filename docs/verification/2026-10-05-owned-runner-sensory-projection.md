# Owned runner sensory projection: code and verification checkpoint

The bounded projection samples the original runner's senses from the executed
eleven-player/fifty-five-part field cut. It authenticates the original runner,
observation model and official occupancy provenance in one SQLite read snapshot.
The exact physical cursor supplies the observable ball state; an unresolved
response supplies no invented future state.

This is an unpersisted sensory projection. `knownContext` remains null, and force,
tag-up, owned race/threat cues and consumed signals remain unavailable. Original
starting-base and ordinary next-base labels are provenance, not live entitlement.
There is no new durable observation, knowledge consumption, decision, controller,
motor adoption, rule result or calibration. The existing ten-player observation
owner and unsupported runner consumers retain their boundaries.
