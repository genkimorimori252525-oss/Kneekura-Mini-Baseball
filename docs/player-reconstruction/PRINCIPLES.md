# OB選手再現 — 原則と決定境界（v1）

> **ユーザーが明示した設計原則:** `2026-10-16 / APPROVED DIRECTION`。ここに「検証済み能力係数」はない。技術的にまだ提案の部分は別記。
>
> **対象:** 歴史的OBの「全盛期」テンプレをペナントへ投入する場合。現役選手の通常成長・加齢や若手の覚醒には自動適用しない。

## P-001 — OBの基礎能力値はペナントの年次が変わっても固定

- OBを一度作成したら、そのモードでは**スキルの原因となるTrue Ability/Physics/Technique Source、初期に保存した公開能力値・本人の基礎技能/個性Profileは原則固定**。長期成長・年齢劣化・スランプで恒常能力そのものを上書きしない。
- 試合/シーズンにおける一時的な **execution、Condition、観測からの相手学習、対戦環境、疲労、偶然**は変わり得る。変化するのは年次成績と実際の運動・判断状態であり、元の「全盛期OBの恒久能力」ではない。
- **表示への注意:** 既存正本02は所属リーグ相対の公開能力投影がリーグ人口に応じて変わり得るとする。ユーザーの「OB能力値は変動しない」はOBカードの固定評価にも及ぶものとして尊重し、後日の実装で固定のOBカード基準Snapshotと現在リーグ比較の副次Projectionを区別する提案とする。ただし04等の正本を黙って変更しない。未解決インターフェース判断と明示。

## P-002 — 「全盛期に到達可能」と「毎年全盛期」は別

**「全盛期の55本塁打を出せる王貞治でありながら、毎年55本を打つわけではない」** は引継ぐべき原則。

- 当時と比較できるリーグ水準・競技日程・打席機会・球場・投手/守備/規則なら、正史シミュレーションを多数のシーズンseedで回したときに、実際の全盛期に相当する成績へ**現実的な頻度で到達可能**にする。
- ただし毎年の最高記録の再演や、55HRなど特定数字のハードしきい値への強制はしない。高到達可能性と長期代表値は別の校正目標。
- 史実の最高年度を、普段の平均成績として無条件に設定しない。高い下限も高い上限もEvidenceに応じて扱う。
- 同じ選手を10回ペナントに入れた場合、固定能力値でありながら異なるホームラン数・打率・四球・奪三振、出場機会の違い等が再現できなければならない。
- 55HR/140試合と51HR/130試合を単純な絶対本数だけで比較しない。PA、戦術環境、リーグ水準、得失点環境を揃えて校正。

## P-003 — 全盛期「複数年の集計」から能力を推定する

- OBの代表能力を**単一年のベスト成績そのもの**や、各年に恣意的に最高だったミート/パワーをパーツ合成した理想選手から作らない。
- 歴史上の**全盛期ウィンドウ**を複数年で定義し、その全盛期年の記録を**打席数・打数・投球機会等、適切な分母で集約**する。
- 期間は選手ごとに合理的に指定する。前後の普通の年・不振年を意味なく除いて上方バイアスを作らない。全盛期の選び方を確定したら、あとから成績が合わないためにこっそり年を選び直さない。
- **全盛期ウィンドウ内の平均的な実力**と、その選手の**突出したシーズンを生み出せる潜在的な実行上限/分散**の両面を校正する。
- 生の年ごとの打率を同じ比重で単純平均しない。まず各年の `H / AB`、`HR / PA`、`BB / PA`、`K / PA` 等の機会正規化、時代・球場・相手・敬遠/故意四球の区別を行う。具体的な統計推計方法は [METHOD-V1-PROPOSAL](METHOD-V1-PROPOSAL.md) で未Freeze。
- 同年のリーグ環境を再現できない場合は、比較の限界を併記。「55HR保証」や「同じ数字へ到達できるのが正義」という断定をしない。

## P-004 — 一発屋/単年突出選手にも**振るわない年**が必要

- 1つの歴史的突出年だけを毎年の通常能力とみなさない。たとえば60HRの年を再現できるSourceを持つとしても、低めの年に現実的に着地できる余地を残す。
- 突出年を生んだ原因が恒常技術、シーズンを通じた技術/準備、当日のCondition、環境、使用球・球場、打席数、単なるプレーのばらつきのどれかを、資料の範囲で推定する。
- **一発屋は能力が毎年別人になることではない。** ペナントのOB技能Sourceを固定し、観測できる実行・機会・環境の違いでシーズン成績が異なる構成を優先。
- すべての単年突出選手に機械的な「不調年を50%」「特定シーズンに必ず60HR」などのタグや直接Buffを割り当てない。

## P-005 — OBの性質を直観で上書きしない

- 公開ミート/パワー/選球眼/走力・守備適性、既存TraitやGreenは、独立した技術・判断・身体・行動Sourceの根拠から推定し、重複させない。名選手だから全部S、人気だから強い、ではない。
- 「引っ張り屋」は引っ張り方向の打撃**技術**であり、Direction Intentの固定確率とは別。極端な引っ張り志向に逆方向結果が生じても矛盾しない。**王貞治の候補Traitは広角打法より引っ張り屋を優先**（具体的Tierの付与判定は歴史的Evidence/Skillの比較で校正）。
- 「プルヒッター」と「引っ張り屋」は `09` では同一Familyの候補であり、重複で二つ付けない。広角打法と流し打ちは「引っ張り選好」の反対Traitではないため、否定材料も根拠なく作らない。
- 王への過去の `ミート96／パワー100／選球眼99` 等は**試作の主観査定**であって正式に校正済みの結果ではない。元能力・実測・リーグ環境との照合で再評価する。
- 勝負師/対左投手など、実績が少ないものは `UNVERIFIED` とする。得点圏打点や表面の四球数だけでTraitを推定しない。

## P-006 — 勝敗の数字を後付けで作らない

- スイング、球道予測、フォーム、打点、力の伝達、打球、守備、走者、公式記録の正史因果で年次成績が生じる。選手テンプレに `observedHRs=55` を渡したら必ず55HR、などは禁止。
- Calibrationで期待値・分散の大きな差異が出たら、どの原因モデルが不足しているか調べる。検証のために生成選手へ根拠のない「ホームラン運」をつけることは禁止。
- 実在人物の特殊な史実を再現するために、この人だけの分岐/個別BuffをCoreへ追加しない。能力Sourceと試合環境を共有の一般モデルに渡す。

## P-007 — 成長・調子・心理の既存契約を保全

- [Trait 08 `15.12/15.21/15.36](../game-design/08-player-traits-design-seed.md): 普通の`Condition` は当日の物理・技術発揮に影響する。疲労・スタミナ・回復の同じ原因を2回適用しない。
- [心理05](../game-design/05-psychology-emotion.md): 感情の小変化は `ActiveEmotion` 発火までは直接能力Buffにしない。
- [育成53](../game-design/53-player-development-trajectory-breakthrough-v1.md): 選手の長期成長モデルは通常のCareer向けであり、固定OBモードでは恒常技能書換えを無効化/隔離する。
- [Season Expression Proposal](SEASON-EXPRESSION-PROPOSAL.md) は**提案**。季節ごとの調子の具体的発生式と時間窓、4段階等は正式採用・計測されていない。旧「流れ」案もまだ未確定であり、OBの成績分散のために裏から正式化しない。

## P-008 — 必ず残す証拠

各テンプレには `playerID / variantID / sourceURLs / retrievedAt / statsYears / leagueEraContext / projectionVersion / samplingWeightMethod / sampleUncertainty / testSeedRanges / PASS-FAIL-NOT_RUN` と、史実からの解釈・ユーザー指示・モデル上の仮定を区別する欄を設ける。

**決定境界:** 上記のOB能力固定、全盛期複数年の集計、全盛期到達可能性≠毎年の再現は**ユーザー方針**。Season Expressionの数式、全盛期窓の選定基準、OBの公開Rating基準固定方式、金特Tierの閾値は**未確定**。具体化時に史実Evidenceと既存正本を突き合わせる。
