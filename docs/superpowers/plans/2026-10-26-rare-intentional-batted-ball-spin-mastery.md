## 0. 今回の確定方針

**自然な回転は全打者に発生する。しかし、どちらへどの程度曲げるかを意図し、実際のバット操作で再現性よく生み出す技能は別物であり、極めて希少な習得型の金特殊能力を中心に表現する。**

1. 全打者にフェア側・ファウル側への自然なスライス、フック、トップ／バックスピンを許す。金特非保有者でも偶然の好結果、本人のフォーム由来の回転傾向は存在し得る。
2. 回転の多いフォームは`観測される個人特性`であり、意図して回転を生成できることを意味しない。`ラインドライブ`は既存`09`どおり実際の打球角度分布からのDescriptorであり、追加Buffに変更しない。
3. 希少得能は「当たりを強くする」「スライス量を加算する」「ファウルをフェアに変える」魔法ではない。**狙った曲がり方に対応する、身体的に実行可能なバット運動候補を選び、精密に実行できる習得技術**を指す。
4. その技術の保持と**使用意図**は別。金特保持者も普通に打つ、見送る、強振・ミート打ちを使う。使用しない球への隠し効果はゼロ。
5. **「落合博満が将来大量発生しない」**ために極度の習得難度と証拠を要求するが、同時保有人数・出現人数・歴史上の一人制限のようなハードキャップは置かない。
6. 打球初速、回転`Vec3`、打球軌道、フェア／ファウル、ポール際の裁定は**既存の物理・RuleEngineの結果だけ**が決定する。特殊能力が`exitSpin`や公式結果を書き換えてはならない。

## 2. 三層を明確に分離する

| 層 | 源と意味 | 何が可能か |
| --- | --- | --- |
| A. **自然な回転** | 全打者の実際のバット軌跡、投球、摩擦と接触位置 | 偶然のフェード／ドロー、スライス／フック、回転不足や逆回転も成立 |
| B. **回転傾向（Descriptor）** | 多打席の実際の`exitSpin`・回転軸・変曲方向・球道を集計した条件付き分布 | 特定の自然フォームによる偏りを観測・説明する。振ろうとする意思や熟達の証明ではない |
| C. **意図的回転制御（希少な習得技能）** | 独立した実在の練習履歴・技術レパートリー・Motor精度・本人のその球の選択 | フェア側へ曲げる等の狙いに対応したスイングを、可能な範囲で`試みる`。成功は保証しない |

**不変:** A/Bは非保有者にも存在する。Cだけが希少な`SpinShapingTechniqueSource`を必要とする。Bの観測分布をCの保有判定に直接使わない。

| 同一Family排他 | BlueとGoldは同時保有・二重適用しない。GoldがBlueを置換する |

`流し打ち／芸術的流し打ち`、`広角打法`、`プルヒッター`、`ラインドライブ`の既存Familyは変更しない。独立性を認めるのは**「狙った横回転を成立させるための目標Motor動作レパートリーと再現技術」**が他のFamilyから十分に分離できる場合のみ。同じバット面制御Sourceを「ミート+」「流し+」「Gold+」と三重加算することを禁止。

**重要:** Match CoreはGoldの`stateId`やUI名を見て`exitSpin`を増やさない。習得・認証済みの真の`Technique Source`に対応する運動候補と制御誤差だけを受け取る。`Trait Label`を変えただけでは同seedの物理結果が変わらない。

## 4. 技術Source・意思・実運動の契約

`SpinShapingTechniqueSource`（概念名、実装前に既存型と統合）の必要事実は次の通り。

- 当人の`playerId / sourceId / sourceVersion`、習得証拠、認証時点、技術レパートリー（どの曲がり方向／打球領域／投球条件に対応できるか）。
- 対応するバットの面・軌道・接触相対位置・タイミングの**再現精度**。身体の可動域・努力・反応・選球眼とは別の責任。
- `LEFT_FADE`・`RIGHT_DRAW`などの呼び名は**ユーザー向けの説明**。内部の目標は打球の`fieldSide`、予想するフェンス到達帯、望む空中曲がり向きの**条件**であって、「球の回転を直接＋500rpm」ではない。
- 左右打席・球場座標を毎回正規化する。右打者・落合型の「レフト側でフェア方向へ戻る／ライト側でフェア方向へ戻る」を基準Fixtureとするが、左右打者に同じ世界回転軸の符号をハードコードしない。
- 型・数値・最適化方式・技術閾値は未校正。別の万能`spinPower`公開能力を新設しない。

```text
本人の事前予測・観測した投球／カウント／監督指示
 + 本人の通常打撃方針・DIR（PULL/CENTER/OPPOSITE/REACTIVE）
 + 認証済みのSpinShapingTechniqueSourceと身体・バットの制約
   → [通常スイング候補 + 習得済みの場合だけ追加される回転操作候補]
   → 本人の主観的な球道と実行可能性から候補選択（無理なら通常案）
   → 一組のBAT/SWG SwingMotorTarget → 時間連続の実バット動作
   → 既存RigidBatBallContact（実投球で唯一の実接触）
   → exitVelocity + exitSpin → 既存Aerodynamics / Flight
   → 球場・守備・Fair/Foul・Official Ruling
```

- **不正なオラクルを禁止:** 回転操作候補の比較には打者が`その時点で知る予測`しか使わない。実際の投球最終位置や「成功したときだけ再試行」を知ってから候補を変更しない。
- **技術を使わない自由:** 本人の意思が通常打撃・引っ張り・ミート優先なら特殊動作は不採用でよい。金特保有者が毎球必ず曲げる設計は禁止。
- **物理Tradeoff:** 操作に必要なバット面・打点・相対速度の選択で、打球初速・角度・接触確率・逆回転・空振りなどが実際に変わり得る。固定の「Goldはミート−X」のような架空Debuffは付けない。
- **計算量:** 既存のMotor候補評価に限定して決定論的・有界な候補数を使う。新しい独立物理エンジンや毎球無限探索、レンダリングFPS依存の探索は禁止。

## 5. 落合型のポール際技術とフェア／ファウル

- 参照史実：落合博満は2018年のテレビ出演で**レフトへのフェードとライトへのドローの習得に3年**と語ったと報じられた。本人の打撃感覚の説明も伝わるが、当時の正確な3Dバット軌道・打球回転軸が計測されたことまでは証明しない。再現目標は**検証可能な運動・物理機構**であって、回顧談を確定的な接触係数へ変換しない。
- 左右のポール際では、狙った`field-side`の**空中通過経路**が物理的にフェアを満たしたときだけ成功する。**ボールが一度ファウルと公式確定した後で曲がってフェアになったことにはできない**。
- 接触の瞬間にレフト／ライトへ射出したかだけでファウルを判定しない。飛球の最初の接触、守備者の最初の触球、壁・ポール・場外へ出る位置と時刻を、球場形状と適用ルールで判定する。
- ポールはフェア側。空中での壁／ポール越えを扱う球場・RuleEngine接続が未完なら`NOT CONNECTED`とし、**描画で内側に見えたから本塁打**等の暫定裁定は禁止。
- 「ポール際を狙った」だけでHRを保証しない。飛距離不足・無回転・打球方向ずれ・守備による捕球・投球の読み違い・球場差も合法。

## 6. 希少性と長期ペナントの取得方式

既存`09`の`Trait Density Guard`と`53`の`Catalyst → Hypothesis → Repetition → Consolidation`を使用し、**任意の高ミート・高パワー選手が自動的にGoldを保有することを禁止**する。

1. **発見:** 本人の適性・技術的仮説・練習環境・Coachとの実際の交流などから専用の学習課題を発見する。身体能力が高いだけ、ヒットを打っただけ、誕生日になっただけでは発生しない。
2. **習練:** 限られた日数・体力・練習機会・Coaching Attentionを使い、対応する投球・打点・バット動作で十分に異なる反復とFeedbackを積む。反復ごとの超低確率くじは禁止。
3. **技術検証:** 打撃練習で、同等の投球とフォーム条件に対して、通常フォームとの**狙った回転差・方向差・実現精度**を比較する。偶然の曲がりや数本の好結果だけでは習得扱いにしない。
4. **定着:** Source-owned練習・試合履歴とConsolidation証拠が揃って初めてBlue、さらに異なる方向／状況にも高度な制御が再現できる場合にGoldを候補とする。閾値は証拠と長期発生分布で校正する。
5. **保持と劣化の分離:** 習得済みMasteryは原則残るが、体力や可動域の衰えで使える球が減ることはあり得る。身に付けた記憶を加齢のみでランダム剥奪しない。

**希少性ガード:** 100〜300年規模・複数seedのキャリアを使い、Gold人数・Blue人数・習得経緯・世代間分布・成功した打球の割合を監査し、**一般的な選手のほとんどがこのGoldを取得するような収束を失敗**とする。具体的保有率・必要練習年数の数値は未校正。世界で必ず一人／何人まで、という人数上限を入れず、真に突出した二人目が生まれることは許す。

**OB・選手再現:** 落合型の実装例は史実の技術記述に基づく`HISTORICAL_DESCRIPTION`で始める。物理校正・試合再現が終わっていなければ`MODEL_UNVERIFIED`と明記する。回顧談だけから「バット角度X度／回転Yrpm／毎年HRを何本増加」といった測定値や保証成績を捏造しない。

| SPIN-17 | ポール命中・ポール内側／外側通過・球場差を適用RuleProfileで判定し、未対応は未対応と報告。 |
| SPIN-18 | Goldでも必ずフェア・安打・HRにならない。届かない球／低速打球／捕球はそのまま。 |
| SPIN-19 | 流し・引っ張り・広角の技能Sourceと同じ誤差改善を二重に入力しない。 |
| SPIN-20 | 単発の偶然のフェア側曲がり・1本のHR・高ミートだけではBlue/Gold習得不可。 |
| SPIN-21 | 同一Episodeの反復抽選や架空Coachによる即時習得、加齢だけの習得を禁止。 |
| SPIN-22 | 100〜300年・複数seedで希少なGold分布を保ち、人数ハードキャップはない。 |
| SPIN-23 | セーブ／ロード／過去のReplayで習得日付と当時のSourceが不変。 |
| SPIN-24 | 表示FPS／MiniとNaturalのカメラ／得能のUI名称で、同seedの実接触・飛行・公式結果不変。 |

## 9. 当面の非対象・史実ソース

- **禁止:** Gold保有なら必ず回転を足す、金特取得で本塁打率+X%、試合結果を見てからスイングを作り直す、全員同じ回転制御技能を通常成長で量産する、試合物理の複製。
- **未校正:** 回転操作の実際の習得率、練習所要日数、バット角度から打球回転への個人精度、左右両方を操れる技能の実測頻度。未検証値を固定係数として実戦導入しない。
- **史実の根拠と限界:** [Lmaga.jp 2018-05-31（落合本人の3年の発言）](https://www.lmaga.jp/news/2018/05/42044/) / [スポニチ 2022-10-05（本人のスイング感覚）](https://www.sponichi.co.jp/baseball/news/2022/10/05/kiji/20221001s00001000707000c.html) / [週刊ベースボール（1985年の特訓説明）](https://column.sp.baseball.findfriends.jp/?id=097-20200418-14&pid=column_detail)。いずれも**打撃の意図・習得過程についての史料**であり、当該打球の回転数や衝突幾何を測定した3D実験データではない。
- **適用ルールの独立性:** [MLB Foul Ball Glossary](https://www.mlb.com/glossary/rules/foul-ball) はフェンス／ポールでの法的判定の一般参考。ゲーム本体は対象のNPB年度`RuleProfile`を正とし、MLB資料を無条件に上書きしない。

**最終原則:** **「珍しい打球」を抽選で生むのではなく、「珍しい運動技術」を本当に身につけた選手が、通常の野球物理の下で珍しい打球を試みられるようにする。** 得能はその真の習熟を表す。落合型の天才は極めて希少でありながら、起こり得る。
