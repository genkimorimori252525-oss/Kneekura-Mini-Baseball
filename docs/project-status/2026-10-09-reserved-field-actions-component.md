# Reserved physical field actions component

This opt-in extension continues the ordinal-three-and-later physical episode.
It uses the existing field-step archive and current cumulative lifecycle view.
Legacy field-step Sources and snapshots keep their original byte shape.

The closed accepted action union now connects:

- An actual field-cut sensory sample, with the original ten actor curves, field
  geometry, current effective observation calibration and an explicit view.
  Observation history is local to the same physical episode and defender.
- An accepted contextual-priority Source to the existing defensive candidate and
  decision/first-step timing calculations. Movement targets come from that
  original perceived ball sample. Nominal observation, decision and locomotion
  models retain their matching normal fielding-model identity.
- A due ball-pursuit or hold decision to the existing rated locomotion kernel.
  The Native adapter reconstructs the defender self from owned canonical curves
  and the original body model. Each selected defender requires the current
  member/view locomotion calibration; all other bodies retain their actual
  acceleration. The complete ten-person composition advances only through its
  existing bounded command coverage. No caller acceleration, self, decision
  result or future physical state is accepted.
- An actual sole-defender-glove candidate to incremental scheduled acquisition.
  The existing Core energy and recorded-tick fence controls progression.
  Pending dissipation/fence and interrupted captures have no carrier or cursor.
  Secured acquisition supplies the original possession cursor for retained or
  newly selected movement. Sensory/decision work between capture checkpoints
  does not erase the original capture progression.

The shared locomotion function now accepts a structural self while preserving
its existing caller's full type and result; the new family retains its distinct
provenance. Two explicit Core response tags represent capture pending and
interrupted projections. The lifecycle outcome census includes the new actual
acquisition evidence and adopted field curves for controller retirement. It
adds no new fair-ball official endpoint.

## Author feedback and remaining integration

The focused author configuration is
`vitest.reserved-field-actions-author.config.mjs`. Its Source and calculation
cases cover due-time rejection, effective acceleration, all-ten contribution,
foreign/stale input rejection, partial capture, recorded-tick fencing,
interruption, secured possession and carried continuation. Model/calibration
reads are explicitly mocked in the movement calculation cases; these are not
Native ownership or genuine fixture qualification. The combined source still
requires its single compiler, independent review and selected Native scenarios.

This batch does not select new numerical calibration values or invent a
controller-renewal policy. Movement is bounded by original role/body coverage
and the existing one-segment locomotion kernel. Broader command renewal beyond
that accepted extent, operation-aware movement during unfinished capture,
throw/release wiring, runner and foot/base evidence, and fair-ball terminal
closure remain separate capability boundaries. Autonomous production of
priority and fatigue-response Sources also remains outside this component.
Protected stance/runner owners, presentation and home-PC CI are unchanged.
