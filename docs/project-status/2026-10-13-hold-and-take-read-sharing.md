# Completed hold and second-TAKE sharing in the existing read phase

## Cause and bounded change

Different historical field-rule views use the same original occupied-runner
hold. The generic running archive authenticated its row and replayed enrollment,
actor, participants, body/model and hold curves on every concrete hold read.
The exact completed hold is now shared by its full reference through the
existing lifecycle memo. Generic archive reads and the hold writer are unchanged.
Each aggregate hold caller still checks the expected runner set, actor,
enrollment and its own requested finite time coverage.

Lifecycle's private second-pitch map did not cover direct calls from initial
live continuation. Each public historical second-TAKE read rebuilt its lexical
assembly, including the 32 calibration checks and pitch calculation, before
checking all five saved rows. The public completed bundle is now shared through
the existing continuation memo, keyed by its full reference. The internal
completed-id reader, fresh/owned-append assemblies and writer protocol are
unchanged. Missing, partial or failing proofs are never published.

Both public readers enter the existing phase before cloning and validating the
reference. A caught invalid request now expires the enclosing proof, extending
the existing fail-closed behavior to their public input boundary. The complete
value/reference comparison succeeds before a memo entry is published. Returned
holds and all six members of the TAKE bundle are recursively frozen. There is
no persistent cache or authority-callback sharing.

## Connection and mutation boundary

ATTACH does not change the existing phase signature. Original body/model owners
already reject attached databases and temporary owner replacements. The concrete
hold, historical TAKE and field-rule pair readers now call the same existing
`assertBodyCompositionNativeConnection` before each memo lookup, including hits.
This also closes an ATTACH gap in the earlier field-rule pair optimization.
Pair current/historical admission and inactive-field pending handling stay
before its lookup.

Native/query-only entry, before/after signatures, private savepoints, cycle
rejection and failure invalidation remain in the existing phase helpers.
Mutation, rollback/rebegin, commit and independent retries cannot inherit the
completed proof. No journal writer is wrapped in an enlarged read phase.
