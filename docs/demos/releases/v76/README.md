# v76 空中球とゴロの表示分離

「俯瞰：空中のボールの倍率」を変えても、地面付近の球やゴロの浅い跳ねは元の大きさを保ちます。球の下端が地上0.5mまでを保護し、0.5〜1.5mで空中表示へ滑らかにつなぎます。空中倍率2以上の高い球は旧表示のままです。倍率1は従来表示で、1〜2では基準サイズも連続的に補間します。

「俯瞰」の全体倍率は引き続き全ての自由球を拡大します。空中用倍率とは別の設定です。初期値は通常1／俯瞰1／空中2。グローブ内の球は非表示、ボールの物理は変更していません。

v75の技術得能・能力編集・実測フォーム・カメラ・試合進行を継承。設定と試合用JSONは互換です。
