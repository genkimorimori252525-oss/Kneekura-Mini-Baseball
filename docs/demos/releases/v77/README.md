# v77 投手調整と独立得能

- [通常試合](game.html)
- [カメラワーク調整室](camera-workbench.html)
- [選手メーカー・投手調整室](maker.html)

得能の付与・段階・効果倍率で、公開能力と詳細の基礎値を変更しない独立方式を追加しました。送球Dは中立、送球Aやストライク送球は実送球の方向誤差へ作用します。悪球打ちの技能強度も得能の設定として編集します。一般能力への二重加算は行いません。

実働は17系統。従来13系統に、内角攻め／内角無双、ハイボールヒッター／高球必打、ローボールヒッター／低球必打、打球反応○を追加しました。名前と約1秒の「?」説明を分け、未接続の緩急○・牽制○・立ち上がり○は有効スイッチとして出しません。元の119項目catalogは保持します。

メーカーの「投手調整」で投手・球種・狙うコースを選び、球速、回転数・方向、リリース位置、投球動作を編集して試投できます。投手／捕手の試合描画、横・上の図、正面の到達点で比較します。変化量は同じ初期位置・初速度の無回転球との差です。投球動作の設定例は作者モデルであり、実測フォーム集ではありません。

初期は人間用表示です。「AI」モードは同じ選手JSONの編集・検証・結果取得に使い、切替だけでは能力や試投を変更しません。作成した試合用JSONは通常HTMLの能力読込へ渡し、新しい試合から適用します。進行中の履歴は変更しません。

旧JSONは読込だけで変換しません。「旧得能を独立方式へ変換」は明示操作です。旧送球は変更前の基礎値を保存していないため、現在のSIを維持して独立送球を未設定にします。旧緑特は保存baselineを復元して実行時に一回だけ作用させます。元ファイル・初期20人・673実測打撃記録は維持します。
