HTMLは単体で保存し、ブラウザで開けます。外部通信やサーバーは不要です。

メーカーの「打者のコース・方向とシーズン成績」で内部63マスを編集します。クリックは得意（赤 .330）→苦手（淡青 .180）→普通（灰 .250）。選択マスは数値でも変更できます。ここは設定する参考値で、実際の打率を保証する値ではありません。方向の扇形は狙う配分、下の実績は物理接触から得た結果です。

通常試合は「シーズン・コース別成績」からシーズンを作成・選択し、「新しい試合」で開始します。完走後に一度だけ記録します。公開9分割はストライクゾーン内だけを集計し、外側・範囲外・位置不明を分けます。0打数と判定不足は「—」で表示し、確認済みの小計は別に示します。

成績帳JSONを通常試合とメーカーで受け渡せます。メーカー全体JSONにも `courseSeasons` を保存します。ブラウザ保存は明示操作で行い、起動時の自動復元はしません。HTML間で同じ保存状態が自動共有されるとは扱わないでください。

練習は今季の対応だけを変えます。先天的な設定・公開成績には加算しません。シーズンを締めると、試合のH/ABと打数に応じて長期特性を小幅に更新します。締めは一度だけで、締め済みシーズンへ試合を追加できません。進行中のシーズン付き試合がある間は、成績帳の差し替えと締めを停止します。不要な試合を破棄する場合は、単独試合を選んで新しい試合に切り替えます。

記録は `local_physical_scoring_v79_1`、学習は `local_course_learning_v79_1` の版付きローカル方針です。安打・失策・野選・犠打飛の根拠が不足する記録は確認中として残します。Native認証付き公式採点、100試合分布校正、実機スマートフォン検証は未完です。カメラ・17得能・673実測打撃資料・初期20人の基礎設定は維持します。
