# v78 球種と縫い目物理

- [選手メーカー・投手調整室](maker.html)
- [カメラワーク調整室](camera-workbench.html)

HTMLはダウンロードして通常ブラウザで開けます。各HTML内に必要なCoreと描画素材を含み、外部保管庫なしで動きます。

メーカーの「投手調整」で、15基本分類と9派生の24設定例から球を追加できます。球速・回転数・回転の向き・縫い目の向き・リリース位置を設定し、同じCoreで即試投します。初期20人の能力と所持球は変更していません。既存7球を新形式へ移す操作は明示的に行います。

「オリジナル球の保管庫」は別タブです。名前を付けて保存し、編集は版履歴として追加します。別の投手へ付けると選んだ版の数値をコピーするため、後日の保管庫編集は既適用選手へ波及しません。保管庫JSON／メーカー全体JSONの保存・読込と、端末への明示保存・復元ができます。未保存の編集は保存または取消まで切替を止めます。

「回転の再現性（最低維持率）」80%なら、基準1000rpmから800〜1000rpmへ毎球下振れします。98%なら980〜1000rpm、100%／旧省略は固定です。方向と公開能力・得能は変えません。狙いを決めた後の実回転を世界へ渡すため、失敗を予知して補償しません。

新しい球の設定例には、ナックルの向き依存の変化と縫い目の横力を扱う版付き近似を含みます。同じ縫い目姿勢が力と描画に使われ、捕球・バウンド・再送球でも引き継ぎます。係数は研究を参考にした作者モデルで、選手別の実測校正やCFDではありません。世界中の呼称や全空力を再現したとの主張はしません。

通常試合で能力JSONを読み込み、新しい試合から適用します。所持球を設定した投手の球種メニューとAUTOはその所持球を使い、オリジナル名も配球履歴へ表示します。進行中の記録は書き換えません。独立17得能、人間／AIモード、従来カメラ・実測打撃軌道を継承します。

俯瞰の「高さの遠近感」は初期2です。地面から2mの自由な打球を4m相当の投影サイズで描きます。画面位置と物理は実高度のまま。ゴロの基準白点、他視点、投球・送球、保持球非表示を変えません。旧保存の直径倍率は旧方式として読み込み、設定変更で新方式へ切り替えます。
