「ボールの表示倍率」→「俯瞰：高さによる拡大」を調整できる。初期値1は従来表示。1より大きい値では、同じ場所の地面球を基準に、実際のカメラ投影で生じる高さの遠近差を指定倍率で強調する。1.5は遠近差の1.5倍で、球全体の最大サイズを1.5倍に制限する意味ではない。例えば地面比1.2の実投影なら、1.5設定で地面比1.3になる。

地面球と初期表示を維持し、物理は変えない。既存の俯瞰全体倍率とは独立する。調整室にも同じ欄があり、設定JSON／再現sessionへ保存できる。旧JSONの省略値は1。明示した高さ倍率はv65の意味で読む。捕球した球は表示しない。

```text
node tools/browser-bridge/build-v65.mjs
```

検証後に `py -3.10 -X utf8 tools/browser-bridge/package-v65.py` で配布する。v62〜v64と同じNative Core、打者カメラv63／投手v62を継承する。元全計画と未達は継続する。
