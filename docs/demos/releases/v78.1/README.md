# v78.1 投球の多方向比較

[選手メーカー・投手調整室](maker.html)

「横・上・投手後方・捕手・左右打者から同じ軌道を見る」を開くと、従来2図に加えて投手真後ろ／捕手正面／右打者／左打者の4図を確認できます。緑は実投球、灰は同じ投げ出しで回転だけ0にした比較球です。

固定した目の位置から同じ軌道を透視投影します。図ごとの拡大は表示だけの操作で、外すと同じ視野倍率になります。試合カメラの首・視線追従を再生する図ではありません。基礎v78のCore、元の投手UI、通常試合renderer、初期選手、バット集を変更していません。無回転にも縫い目力が残る既存の意味を維持します。
