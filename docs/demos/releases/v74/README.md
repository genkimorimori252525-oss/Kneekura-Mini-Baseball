# v74 用具・公開能力・打球比較

- [選手メーカー](maker.html) — バット軌道の「この選手のバット」で長さ0.2〜3m、重さ0.1〜5kgを編集。公開能力はメーカーのみ100超を扱う。
- [通常試合](game.html) — 保存した「試合用能力JSON」を読み込み、新しい試合を開始。
- [カメラ調整室](camera-workbench.html) — 同じ通常試合を使用。

100超の能力はメーカーでSと数値を表示。選球眼は従来どおり1〜100。試合画面には能力表がなく、100超の公開値は表示しない。物理値を100相当へ切り詰めない。用具の上限は実験用で、現実の推奨値ではない。

弾道別打球比較だけ全幅へ広げ、打者目線の直前に計算/次球/再生/弾道/時間操作を配置。バット軌道paneの既存配置は維持。描画の長さと衝突用長さを同じ選手設定へ接続し、質量変更後は比較を再計算する。

設定JSONは従来互換。Core変更のため、古いCoreで保存した試合replayは混用しない。初期20人と元673実測記録は変更していない。
