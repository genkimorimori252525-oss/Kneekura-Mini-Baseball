GitHubでHTMLを開いた後、**Download raw file**から保存し、PCのブラウザで開いてください。両HTMLは外部通信なしの自己完結版です。GitHubのコード表示画面上ではゲームは実行されません。

メーカーで「試合用能力JSON」を保存し、通常試合の個人能力読込から読み込み、新しい試合を開始すると反映されます。公開能力11項目と内部SI40項目は同じ設定を表す編集方法です。投手・野手に応じた主能力を表示します。公開編集の対応付け・初期SIは暫定で、実測された選手の絶対能力や公式リーグ評価とは区別します。

Gitの改行変換によるSHAの相違を区別できるよう、検証時のCore103入力・bundle・各データ・manifestを元のbyteのままZIPに保存しました。ZIPのCRCと全ファイルbyteを照合済みです。これは検証用スナップショットであり、Node依存を含む独立開発環境一式ではありません。

通常試合は511球で9回表終了まで検証済み。ホームがリードしていたため9回裏はありません。51対57という未校正の1試合であり、現実の成績分布を証明したものではありません。スマートフォンは幅390pxで確認していますが、実機確認は未完です。
