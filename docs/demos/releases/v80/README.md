# v80 — 球種の方向別メニュー

[選手メーカー](maker.html) の投手調整室で使います。

所持球は常設し、候補は「直球／三塁側／一塁側／落ちる球／特殊・小変化」のタブに分けます。現在のカタログの15分類・24設定例をすべて含みます。左右の投手に応じて候補を振り分けます。捕手から見て右が一塁側、左が三塁側です。同じ種類を複数追加でき、元の矢印イラストとオリジナル球の保管庫を維持しています。

候補の方向は球種の傾向を案内します。矢印は回転による力を示し、実際の落下・縫い目の力を含む球筋は既存の試投で確認します。未保存入力がある間は追加・所持球の選択を止め、入力を保持します。タブは矢印キー・Home/End・Enter/Spaceで操作できます。

共有Core、元の能力UI、試合renderer、673実測資料、シーズン機能はv79と同じです。[通常試合とカメラ調整室](../v79/README.md)を引き続き使います。[検証結果](../../../verification/releases/v80/README.md)。今回の追加版はローカル保存です。
