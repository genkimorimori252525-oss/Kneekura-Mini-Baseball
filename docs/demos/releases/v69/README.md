ページ上部の「弾道ごとの打球比較へ」で選手作成内の比較画面へ移動する。上の選手・打ち方を選び、投手・球種・コース・ばらつき番号を設定し、「同じ球で4段階を計算」を押す。

4段階は同じ個人能力・同じ測定フォーム・同じ投球・同じ狙いとタイミングのずれを使う。変えるのは弾道の段階だけ。初速・打ち出す角度・回転数・最初の着地までの距離を一覧にし、同じ投球開始時刻・同じ縮尺で再生する。空振りも表示し、当たる番号の自動選別や打球の補正は行わない。

初期の「比較中は必ず振る」は、振る判断だけを一時固定する。ミート・パワー・タイミング誤差・用具・実効得能などは保存した選手の値を使い、ロスターを変更しない。オフなら振る判断も保存設定を使う。元の能力・フォーム・角度の編集は通常試合用JSONに保存する従来手順を維持する。

「打点を拡大」で接触付近を大きくし、比較図は最大16倍まで拡大・ドラッグ移動できる。「打球全体を表示」で戻す。黒いバット画面にも0.25〜12倍・バット中央・ドラッグ・ホイール・2本指拡大を追加した。この表示設定は従来の全体JSONへ保存でき、旧JSONは初期表示で読み込む。

比較の条件と計算結果は専用JSONへ書き出せる。これは再計算・監査用の記録で、専用JSONのUI再読機能は今回含めない。

比較は守備者と壁を置かない観測。最初の着地点は公式の安打・本塁打・ファウル確定ではない。回転数だけで飛距離を決めず、衝突後の速度・回転・空力・地面を共通Coreで計算する。通常試合・カメラ調整室はv68を維持する。

```text
node tools/browser-bridge/build-maker.mjs ../../outputs/にーくら野球メーカー_v69_打球比較と拡大版.html --executable-traits --measured-library --ball-comparison --roster=docs/demos/live-game-roster-v62.json --catalog=docs/demos/live-game-roster-catalog-v62.json
```

OpenBiomechanicsの元データ・ライセンスはHTML内と[v68の原資料監査](../../../verification/releases/v68/measured-library/README.md)に保持する。元全計画・未達と原FAIL／UNKNOWN／Charter HOLDは継続する。
