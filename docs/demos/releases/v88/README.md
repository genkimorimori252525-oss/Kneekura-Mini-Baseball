HR見送りはフェンス越えの観測後1500〜2000ms。ホームランごとにseed付きで抽選し、同じ記録の再読・逆seekでは同じ長さにする。確信HRで投手視点を維持していれば投手のまま、既に守備視点へ移っていればその観測者のまま見送る。確信HRが後から観測された場合も過去の守備視点を優先しない。

空振りの捕球成立後も、登録済みの実測バットの残りを再生する。実測終端を描いてから既存の身体フォロー待機を終える。ボール・裁定・走者・次球時刻を変更せず、第三アウト即benchの既存優先順位を保つ。実測範囲外のスイング軌道を作り足さない。

ハーフスイング生成・停止能力の新設は今回に含めない。Lunaの研究では、ミート能力と停止成功率の直接対応は確認できず、2026 PCLのchallenge記録と全チェック試行の停止成功率を区別した。新公開能力を増やさず既存判断・運動から作る設計案を研究文書に残す。

v87の正方形63区画・13打率・MLB比較・入力復帰、673実測軌道、20選手、既存の描画・操作を継承。実機・100試合・Native認証・空力校正・高負荷時の実FPS改善は引き続き残件。
