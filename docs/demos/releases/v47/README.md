GitHubのHTML表示画面で **Download raw file** から保存し、ブラウザで開く。試合とメーカーは、それぞれ外部通信不要の単独HTML。

中継は直送・保持・運搬と比較して選び、各受球後に持ち替えと送球先を再判断する。走者は実際に塁を踏む連続経路を走り、安全に次の塁へ進める場合は速度を保って旋回する。既存のUI・間・各視点・4px／55ms描画を継承。

メーカーの公開能力は11項目。内部能力の詳細44項目には旋回半径と横方向加速度を含む。能力JSONを保存し、試合の設定から読み込み、新しい試合に反映する。旧JSONも使用できる。

最終Sourceで213テストと全体型検査が通り、通常HTMLの292球で規定9回を完了。Chromeの1200/390px幅でUI・視点・メーカーを確認。
