# v75 技術系得能

- [メーカー](maker.html) — 選手作成→得能から段階と「技術の効果（倍）」を設定。
- [通常試合](game.html) — 「試合用能力JSON」を読み込み、新しい試合を開始。
- [カメラ調整室](camera-workbench.html) — 同じ通常試合を観測。

追加6系統：走塁／バント／守備職人／内野安打／高速チャージ／低め制球。既存7と合わせ13系統。金特は同系統の上位段階。効果0〜2倍（初期1）、0または保有OFFは従来動作です。メーカーで選手ごとに付与し、試合用JSONを保存すると専用動作へ反映します。

走塁は経路、バントは有限速度で構えて引く動作、守備は捕球体勢と持替え、チャージは観測した低速打球への前進、低めは低い狙いの誤差へ作用します。一般能力は保持。段階と係数は試験用の暫定設定です。

能力JSONは従来互換。旧Coreの試合replayは新Coreへ混用しません。初期20人の値、実測フォーム、カメラ、v74の全幅比較配置を継承。原の全計画は継続しています。
