13区画は中央9＋周囲4。区画を選んで値を入力すると図にプレビューし、「数値を選手へ反映」で確定、「未保存入力を戻す」で破棄する。打率.300以上は赤、.200以下は淡青、その間は灰色。実成績の打数0・未確定は「—」とする。先天的な作者基準と実績は別の値。

5方向図は方向の区切りを固定し、塗る面積と割合を変える。内部63分割は詳細欄にまとめ、元画像の正方形・中央赤枠・番号配置を維持する。3役の見誤り・狙いは打率とは独立して設定する。省略時は従来の能力による判断を使う。

2025年MLB値は公式MLB Stats APIの安打数÷打数を合算した比較資料。既存20選手、試合成績、先天設定は自動上書きしない。分類不明10安打／63打数を13区画に振り分けない。方向のMLB比較は分母を検証できていないため生成しない。

旧63区画設定・旧成績帳を読める。13区画編集時も旧作者設定を原本として保持し、解除で戻せる。13↔63の面積加重変換は近似で、往復完全一致を保証する方式ではない。認識の誤差、縫い目空力は実測校正済みモデルではない。実機・100試合の検証、Native公式認証、v84の高負荷時の実FPS改善は残件。
