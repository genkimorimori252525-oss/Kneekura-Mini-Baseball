通常試合にも新しい初期値を反映した。振る前とスイング取得はv59の視線制御を基準にし、実際のバットの回転に合わせた小さな頭の動きを加える。見逃しは投球へ同期し、捕球後の遅い向き直しを行わない。

調整室は初期Aがv59スイング基準、Bが身体連動を加えた設定。設定Bで次を比較できる。

- 「バットに伴う頭の動き」：初期値.025、0で連動なし。
- 「安定中に許す角度／最大角速度」：初期値.04rad／.35rad/s。
- 「スイング前の追従にも選球眼を反映」：初期OFFでv59基準。ONでv61の全投球能力連動と比較。

連動0＋許容角.025rad＋最大角速度.18rad/s＋能力反映OFFで、v59のSWING姿勢を再現する。見逃し判断後の選球眼強化は維持する。早め／遅めのカーブ選択、任意の安定開始時刻、A/B再生、JSON保存も使える。

旧JSONを読むと旧設定を保持する。「Bを改善初期値へ」で今回の初期値に戻せる。投球・打球・実測バット・裁定・AI・能力値はv62と同じ。頭部応答は実測バットを入力とする仮の表示モデルであり、実測された頭の運動ではない。

```text
py -3.10 -X utf8 tools/browser-bridge/prepare-v63-workbench.py

```

検証後に `py -3.10 -X utf8 tools/browser-bridge/package-v63.py` で照合・配布する。凍結v62と同じNative Coreが必要で、変更を検出したらビルドを停止する。元全計画と未達は継続する。
