# 観客とLEDペンライト

2026-10-24 / MB-20261024-BALLPARK-CROWD。本人の直接指定: チーム色のLED、タンボフは赤青、2〜3コマで常時動き、安打等で速く振る。

対象は専用球場設計室と再利用可能なread-only Presentation module。既存の観客群の位置を使い、身体・頭・ペンライトを同じ投影/光点/深度で描く。定員12万人を12万actorへ展開しない。内野/色付き線/狼/屋根/Coreは保持。

2/3コマのscene画像をカメラ/設計変更時だけ生成して再利用する。通常は約400ms間隔、反応中は80〜140ms間隔で画像を切り替える。非表示・停止・旧球場でtimerを止める。reduced-motionを初期停止に反映。明示停止/再開と安打等の確認、イベントID重複抑止を用意。試合の判定は入力イベントを観察するだけで決めない。

新球場自体は未導入のため通常試合接続を完成済みとはしない。表示/反応APIを用意し、今回は設計室で動作・軽量な再生を検証する。データ形式変更は不要。観客色は球場の赤青themeに連動。既存JSON・元V114・v1/v2を保護し、変更前v3を別名保存。

検証: イベント/重複/期限/停止/2・3コマのunit、実Chromeでフレーム差・安打加速・停止・旧球場・テーマ/カメラ更新・低負荷再生（フレーム切替中にscene再計算なし）・保存/履歴・屋根遮蔽・モバイル。全FAILを保持。復旧は変更前HTMLを開く。
