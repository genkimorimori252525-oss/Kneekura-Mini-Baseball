## What is known and what remains unavailable

Original official occupancy identifies the runner's starting base and the ordinary adjacent next-base label. The original activated actor, its official revision and its Match snapshot must be authenticated. These labels do not supply current physical coordinates, current base entitlement, an executed touch, or a completed advance. A body passing near another base must not update them.

There is no existing runner Native owner that authenticates live force/tag-up knowledge or consumes received calls into a runner controller. `ActualFirstBasePlayEndEvidenceFromSqlite.ts` explicitly retains `received_call_controller_consumption_pending`. Core force and tag-up rule functions compute truth; they are not a player's knowledge receipt. Original final/true rule records, later OfficialPlayClosure state and a caller's booleans cannot substitute for that missing information path.

The initial bounded result therefore contains:

- the runner's own sensory receipt at the actual executed field endpoint
- an `originalPublicContext` with starting-base/normal-next-base labels, original activated actor Source, original official revision and Match hash
- explicit unavailable force/tag-up knowledge and unavailable owned runner race/threat-cue generation
- no `RunnerDecisionInput`, issued decision, motor command, control window or settlement result

An empty or unavailable signal/cue path must not become `forcedToAdvance:false`, `tagUp:none`, a fabricated safe-race estimate or `no_actionable_evidence` settlement. Existing `RunnerDecision` and `RunnerDecisionTiming` remain the next consumers once the missing knowledge and cue producers have real ownership. Perception alone is not signal consumption or decision issuance.

## Perception rules

Use the original runner's authenticated observation model and original Player/Person binding. Sample all fifty-five actual curves at the field's true elapsed moment; never sample the rounded event tick or a nominal future controller state. Body-center eye anchoring, relative eye offset, model clock, refresh/memory and explicit occlusion/FOV rules retain the existing convention. The selected runner is the observer; other ten actors are possible perceived targets and all appropriate bodies are occluders.

The real response cursor supplies the observable ball state when available. An unresolved physical response does not invent a post-contact ball state or future coverage. Model/identity/day mismatch, unsupported surface visibility and nondetection retain explicit outcomes. Sensory error comes from the existing calibrated Core machinery and deterministic seed ownership; no new thresholds or defaults are introduced.

`originalPublicContext` is an original-play reference, not live rule truth. Current/next base, force and tag-up cannot be copied from a supplied `CanonicalMatchState`, corrected-rule snapshot or a later official result. `ActualCallCommunication` must still enforce exact recipient/time/physical membership before any future consumer can use call content. A first-base OUT/SAFE call is not automatically a tag-up/force fact or a coach instruction.
