## 欠けの目安（MLB、Lahman 2025）
打撃の項目が入っている割合（各年代）: 三振 1880年代62%・1900〜40年代77〜88%・1950年代〜100%／犠飛 1950年代62%・1960年代〜100%／盗塁死 1910年代12%・1950年代95%・1960年代〜100%／併殺 1940年代77%・1950年代〜100%／故意四球 1950年代53%・1960年代〜100%。守備の出場イニングは 1950年代61%・2000年代〜ほぼ全件。**三振・併殺・犠飛で能力値を換算できるのはおおむね 1950〜60年代以降**。それ以前は欠けを埋めず、時代の平均に寄せるか「不明」とする。

## 時代の出来事（出典つき・確認していないものは仮説）
- MLB 1969: マウンドを15インチ→10インチ、ストライクゾーンを脇の下〜膝頭に戻した（SABR・Wikipedia）。打率+11ポイント、得点+19%。
- NPB 2011〜2013: 統一球。本塁打は1試合 1.86（2010）→1.09（2011）→1.02（2012）、2013年に仕様を実質変更（j-cast ほか報道）。
- KBO 2019: ボールの反発を下げ、本塁打率が約4割減（FanGraphs・Pitcher List）。2020年に戻った。
- **昭和NPBのダウンスイング、時代ごとの攻撃角は資料で裏づけられなかった**（証言・指導論はあるが測定が無い）。攻撃角の実測は Statcast の 2023年以降だけ。→ 推定せず**仮説のまま**。代用の候補は ISO・三振率・BABIP の時代差。
- MLB の打球の型（ゴロ/フライ/ライナー/ポップ）は Retrosheet のイベントで **1990〜2024年はほぼ一定**（F+P は .34〜.37）。**1950年・1975年は軌道コードが13〜14%しか付かず使えない**（1990年は87%）。
- 2015・2019年の MLB のボール、DH の開始年（AL 1973・NL 2022）、2023年の規則変更は、この調査では出典を確認していない（仮説）。

## 選手ごとの手がかり（方針）
- 得意コース: Statcast と PITCHf/x の投球単位データ（**2008年以降**）から、打者×投手の利き手×ゾーンの集計を作る（取得中）。**2007年以前は推定しない**。NPB・KBO も推定しない。
- 左右差・得点圏: 2015〜は Statcast の打席結果から。1950〜2014は Retrosheet のイベントファイルから作れる（未実施）。NPB には左右別の成績が無い。
- 走力: sprint speed 2015〜。それ以前は盗塁・盗塁死・三塁打・併殺で代える。
- 守備: 位置は Lahman・OOTP の試合ごとの出場記録（NPB は 1936〜の試合単位、90万行）。肩・範囲は OAA（2016〜）、arm strength（2020〜）、それ以前は刺殺・補殺・失策・併殺をリーグ平均と比べる。NPB の守備の相対指数は OOTP が成績から計算した値で、実測ではない。

## 球場の寸法と走力の表（2026-11-04 追記。表本体は非公開 repo の `data/mini-baseball/parks/` と `research/`）
- **MLB 球場**（球団×年×球場、1871〜2025、3311行）: 左翼線・左中間・中堅・右中間・右翼線ほかの距離（ft）、壁の高さ、標高（ft）、路面、屋根。Seamheads の寸法を Lahman の球団・球場IDに結ぶ。寸法があるのは 3261行。**三辺の寸法が空なのは 1910年より前だけ**（1870年代の8割、1880年代の7割、1890年代の3割弱、1900年代の1割弱）。2025年の33行は Seamheads が 2024 までなので**寸法は空欄のまま**（埋めていない）。他に、寸法が無い年が 17行（1880〜90年代の一部と臨時開催）。
- **NPB 球場**（球団×年、1936〜2025、1031行、55の球場名）: OOTP の寸法（ft）。**球場名ごとに1組で、年によって変わらない**。改名の前後で値が違う球場だけが改装を表す。標高は元データに無く**空欄**。
- **KBO 選手単位（私的利用のみ）**: 本人の判断で、第三者がまとめた公開スクレイプ（元は KBO 公式、**ライセンス無し**）を 1982〜2025 年（打者 11,632 行、投手 7,675 行、3,510 人）で取り込んだ。**データ本体はどの repo にも置かない**（PC の `K:/kbm-work/kbo/normalized/` のみ）。2008 年以前は打者の 13〜25% の行で四球・三振などが空欄（推定は別列、1982〜2007 の三振率の推定誤差は平均 1.8%）。盗塁・先発数は無し、生年月日は現役のみ。チーム×年の合計との照合では、2001〜2020 年は移籍選手の計上による球団ごとの ±数%の差、1982〜2000 年はリーグで最大 4.4% の余りが出た（原因は未解明）。
- **NPB の選手別・球団別・試合結果（ProEyeKyuu、出典表示つき）**: 1936〜2025 年（1945 年なし）、選手別 打撃51,077 行・投球20,436 行・守備61,636 行（NPB 公式の選手ID つき、日本シリーズ・クライマックスシリーズの行を含む）。**選手の合計は球団の行と 1,032 球団年すべてで完全に一致**。試合結果から球団×年の本拠地球場が分かり、**古い時代ほど多くの球場で主催した**（最多の球場の割合が 0.9 未満の年が 562／1,032、0.6 未満が 143）。環境の例: 本塁打/打席は 1980 年 .0347、統一球の 2011 年 .0148・2012 年 .0138、2024 年 .0153。**データ本体はどの repo にも置かない**（PC の `K:/kbm-work/proeyekyuu/` のみ）。OOTP とは統計値が同じで、今後 NPB の成績は ProEyeKyuu を主、OOTP を能力評価の参照とする。
- **リーグをまたいだ選手の対（私的利用）**: 選手×移籍×（移籍前の最後の2年・移籍後の最初の2年）の表を NPB・MLB・KBO で作った（打者：MLB→NPB 763 件・NPB→MLB 182 件、投手：507 件・205 件。KBO 絡みは韓国出身の 35 人のみで 数件ずつ）。MLB→NPB の打者の 96% が日本以外の生まれ、NPB→MLB も日本生まれは少数で、NPB で先に出た外国人選手の MLB 移籍が多い。**KBO と MLB・NPB を行き来した外国人選手は ID の橋が無く未結合**。球団の改名の対応表（NPB 1,031 球団年、KBO 363 球団年）、NPB 公式の日米野球・日韓野球 7 シリーズ（1999〜2018 年）48 試合の選手別ボックススコア（打撃 1,198 行・投手 431 行、全試合で打者と投手の合計が一致、選手IDは無し）も取得。**データ本体はどの repo にも置かない**。
- **KBO リーグ環境**（チーム×年の合計から計算）: 十年平均の打率は 1980年代 .260、1990年代 .259、2000年代 .267、2010年代 .277、2020〜21年 .266。本塁打/打席は 1980年代 .0162 から 2010年代 .0234 へ。**2019年のボール変更は実測で本塁打/打席 −41%（.0309→.0182）、打率 .286→.267、1試合得点 5.55→4.55**。2020年は .0241（2018年の約78%）で完全には戻っていない。盗塁・盗塁死・故意四球は 2000年以前が空欄。
- **KBO 球場**: 1982〜2025 の球団×年→本拠地（363行、英語版 Wikipedia＝**2次情報**。1982〜2021 の球団×年は実データ（チーム×年）で存在を確認、信頼度 high 237・medium 107・low 19、**球場名が空の年が18行**＝Incheon 時代の球団）。旧球場を含む20球場の寸法（m・ft、infobox の現在値。年ごとの寸法史ではない）。公式（一次）は機械取得が禁止で入手できなかった。
- **NPB 球場の座標と標高**: 55の球場名すべてに座標（Wikipedia、信頼度 low が1件）と標高（国土地理院 DEM、地面の高さ）を付けた。
- **選手IDの突き合わせ**: OOTP の NPB 選手 7927人を Chadwick と Lahman に結び、3429人が照合（Chadwick の key_npb 経由 2870、Lahman 直接 559）、4498人が未照合。未照合の大半は Chadwick に key_npb が無い 1990 年以前の選手。生年月日が 1/1 の行（166）は OOTP の埋め値の疑い（仮説）。KBO は OOTP データが手元に無く未実施。
- **走力の実測**: Statcast の sprint speed（2015〜2025、選手×年、6104行、走った回数つき）を Lahman の playerID に全件結合。年平均は 26.8〜27.3 ft/s。
- 較正への使い方: 球場は `lahman_teamID`＋`year` で引く。左中間が空でも左翼パワーアレー・左中間と中堅の間が入っている年が多い。走力は回数の少ない選手（10〜30回）のばらつきを大きく見る（**仮説**）。
