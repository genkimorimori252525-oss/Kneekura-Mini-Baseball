# 2026-11-02 野球史の再現と較正

本人の指定: 長嶋茂雄やベーブ・ルースなど、データのある全選手の成績を既存の能力値へ割り当て、当時の環境・リーグ・球場を再現したうえで較正する。球場は広さや風向きなど数値の再現で足り、デザインは不要。そのために高速検証が必要。較正の具体的な手順は未決定。順序は打者の現実性 → 史実の較正 → キレ3段階 → 4種類の回転。

## 速度

- 1球の70%が打者のスイング計画で、そのうち大半が同じ原画クリップの証明の再計算だった。`ReferenceBatC1V122` のクリップ解析を再利用して2.2〜2.6倍に短縮。同じseedの全記録のSHA-256が一致
- 残りの主な負荷は入力の複製22%と送球計画19%
- 16並列で103試合/時。全物理だけでは1シーズン2430試合に約24時間かかり、全史の反復較正には使えない

## 手順（本人承認済み）

1. 全物理Coreを正とする
2. 守備を省いた打席専用の高速経路で、能力値から打席結果の分布を取る
3. その結果で能力値と成績の対応を近似し、シーズンを大量に回す。定期的に全物理と突き合わせる
4. 先に1リーグ1年で環境を合わせ、次に選手を逆算し、最後に年代へ広げる

## 検証環境（本人指定）

タンボフはNLB（オリジナルリーグ）でMLBより水準が高く、ドジャース戦では均等に較正できない。

1. 標準リーグ: `tools/release/make-standard-league.py` で全員を同じ平均的な選手にした2球団で、リーグ全体の環境を合わせる
2. 実リーグの再現: 能力分布を持つ名簿で選手差を検証する。全員同じ選手の平均は実リーグの平均と一致しないため、1段階で終えない
