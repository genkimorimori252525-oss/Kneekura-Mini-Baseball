本人の指示。試合に未接続の要素を先にデザインし、後からの追加時間を減らす。参考動画はスポーツナビ一球速報の画面録画で、完全な再現は目的としない。

## 打順・交代

- 打順、代打、投手交代、ベンチの処理は、違和感なく、簡単で機能的にする。

## 詳細表示

- 成績表の位置表記（`(右)`、`右`、`打 右`）は一球速報に基づく。動画の注記は「()：先発」。
- スタメン表示とは別扱いにし、見ようと思わないと見えない場所かタブへ置く。「詳細表示」などで他の試合情報とまとめる。

## 采配カード

- 添付の采配ボタンを参考に、スライド式でコンパクトに見やすく並べる。
- 打者と投手に分け、攻守で分けて表示する。
- 添付の画像のうち「待て」から右（待て、ファイト、超ファイト、強心臓、威圧、熱血）は不要。
- 使うのは、投手が コースおまかせ、内角中心、外角中心、ストライクをとれ、クサイところ、打たせてとれ、緩急重視、低め中心、敬遠、1球はずせ。打者が おまかせ、センター返し、流し打ち、引っ張り、転がせ、犠牲フライ、ヒットエンドラン、送りバント、スクイズ、セーフティバント、盗塁。
- カードは試合を圧迫しない場所に、手札のように、試合画面のすぐ下へ並べる。これは監督モード専用のレイアウトで、他のモードとは異なる。

## 詳細指示

- カードとは別に、強振、センター狙いなど、打者・投手ごとの詳細指示を用意する。初心者も、踏み込みたい上級者も楽しめる構成にする。

## 追加要件（同日）

- 投手の詳細指示は「組み立て」と「決め球」にし、選択肢は直球・変化球を基本とする（「攻め方」は廃止）。
- 走者がいるとき、1ターン（次の一球を投げるまで）に牽制カードを3回まで選べる。走者のいる塁ごとにカードを出し、3回は全塁の合計とする（一塁2回＋二塁1回で合計3回）。塁ごとのカードは本人承認済み。
- 試合状況で選べないカード（犠牲フライ、スクイズなど）は薄くせず、表示しない。
- おまかせカードは選手の顔写真を枠内に収める。
- 対戦データの「今季」は置かず、一球速報と同様に選手名の下へシーズン成績を置く。
- 「捕手側から」は配球図を選んでいるときだけ表示する。
- 選手名の改行はできるだけ避ける。見づらくなるなら改行してよいが、成績表が下へずれないようにする。案では名前の枠の高さを固定し、文字を縮めて1行に収め、15pxを下回るときだけ「・」で2行に分ける。左右打席の表示は名前の下の体格の行へ移した。
- 対戦成績と相手の情報（対右・対左、コース別、打球方向、打球角度）を、詳しく知りたいユーザーが確認できるようにする。ボールゾーンも確保する。見た目は試合HTML風にする。案では配球図の隣のタブ「対戦データ」に置いた。区分は既存の13区画と打球方向5区分（`docs/design-consultation/course-season-v79.md`）を使う。
- 打球結果（ミート、速度、角度など）を、見たいときだけ試合画面に小さな別画面で表示できるタブを置く。案では映像右上の「打球データ」。既定はオフ。
