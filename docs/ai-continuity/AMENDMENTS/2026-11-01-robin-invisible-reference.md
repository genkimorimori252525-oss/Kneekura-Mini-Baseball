# ロビンの消える球: 参考元に合わせる

2026-11-01、本人は「消える球は途中でボールが消えるんだけど、そのまま参考元通りに再現できるかな？」と依頼。ロビン対戦で旧 `RobinPitch.ts` の2種類を原作通り使う方針を維持し、消える時刻・軌道・描画を参考元へ一致させる。物理上の球は消さない。

確認済み: 旧Natural `PracticeMode.ts:869–885` は `hiddenAfterT` から旧 `PitchPath` の `arrived` まで投球を非表示にする。2種類は原本spec上4.3mと9.02m。旧path区間37 framesの位置・表示一致 `1e9375e62d1d46809d680881abf68533`、path末端以降の一部shadow framesの一致 `ebc7700bb9a440f2b434fa5bcda6d6c9`。これらは限定試験で、UI/全状況の完了を示さない。

元コードから、漏球/ground接触後の後続表示は確認できていない。打球でないground/glove/body後は旧到達前の不可視期間を維持し、初期案の「それらの物理接触で即再表示」を原作挙動と呼ばない。一方、実bat接触で打球になった場合、原本 `PracticeMode.ts:889–891,899–904` と `PlayAnimator.ts:85–95` はbattedへ移り `ball.showAt` を呼ぶため、打球を表示するのが参考元どおり。旧到達時刻まで打球も消し続けると推測しない。消えている間の描画と観測・球の衝突が整合することを実Worker/実UIで検証する。旧到達後の未定義部分は既存作業として記録する。
