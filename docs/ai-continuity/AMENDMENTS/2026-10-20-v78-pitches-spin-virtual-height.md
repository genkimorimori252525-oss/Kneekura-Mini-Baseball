# v78 — 球種・回転再現性・俯瞰投影・特殊空力

人間は実在球種全般、名前付きオリジナル球の版履歴・再利用・折り畳んだ保管庫、投手の回転再現性、仮想高度による俯瞰サイズ、最新仕様と他AIへの相談資料のGitHub保存を依頼した。

俯瞰の要求は「地面から2m浮いた球なら倍率2で4m相当の投影サイズ」。表示直径自体の定数倍ではない。位置・影・物理・裁定を変えず、俯瞰の打球サイズだけへ適用する。旧literal diameter設定とは版を分ける。地面の白点、保持球非表示、他視点の方針は継承する。

回転再現性は制球と混同しない。投手詳細の最低維持率80%なら基準1000rpmから800〜1000rpm、98%なら980〜1000rpm、100%と旧省略は固定。名目spinで狙いを計画した後、独立seed streamで実spinだけを下振れさせる。実球の失敗を投手が先読み補償しない。初期20人の実測値を推定して一括変更しない。

主担当は現在の15基本分類と日本の呼称・派生、安定pitchIdと分類の分離、immutable snapshot、通常HTMLへの接続までの確認案を提示した。人間は「ナックルの不規則変化・縫い目の特殊空力も今回に含める」を明示選択した。特殊現象を単に未実装と明示して終える案は採用しない。

特殊空力は既存の描画と同じ縫い目曲線・material姿勢・相対空気速度から滑らかな力を計算する。RK4の各段階、投球→打球→バウンド→捕球→送球で共有する。ランダムな画面揺れ、球種名での到達点補正、既存の認証ガードの弱化はしない。実験で得られた係数オーダーと作者近似の3Dモデルを区別し、校正済みと主張しない。

新API・保存形式は版付きとし、旧7球種・旧AUTO・旧JSONの省略経路を維持する。旧fork aliasを新正式forkballへ黙って読み替えない。既存17得能、実測バット、打者カメラ、既存UI、世界物理優先の原則、元計画の未完を保持する。新依存・設定・lockfile・secret変更なし。ユーザーAGENTS.mdはstageしない。検証後に既存Draft PR #380へ保存し、mainへはマージしない。
