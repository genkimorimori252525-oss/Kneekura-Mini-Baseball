# v83限定修正 — ホームランを守備目線で見送る時間

人間は、投手目線から守備目線へ移ったホームランについて、球がスタンドに入ってすぐ切り替えず、1.5〜2秒ほど見続けたいと明示した。この限定修正は直接依頼の範囲内で実装。先行して提示したFPS/画質/二足移動の2問は依然回答待ちであり、その変更は実施していない。v83はこのHR表示修正の通常HTML/調整室として先に配布する。

基準は既存Coreの `ruleFacts.overFence.tick`。スタンドとの別の衝突イベントは現Coreにない。採用時間はその時刻から1750表示ms。確定済みHRの観測prefixだけを使い、実際に投手→守備へ移る条件を過去のサンプルで満たしていた守備者を維持する。初めから守備機会のない決定的HRで投手目線を維持する既存方針も残す。

HR死球状態でCoreが保存している現在の球位置がある場合は、そのsampleの表示用copyだけを見せる。保持/グローブ内の球は表示しない。Sourceに新しい軌道やスタンド衝突を捏造せず、Core dead/visible/tick/スコア/走者は一切書き換えない。球sampleがないbench期間は確認済みのフェンス到達位置を視線の向きとして保ち、球を捏造しない。1750msの窓を過ぎれば従来のカメラ/進行へ戻す。逆seekも時刻から決定し、実時間timerや乱数を使わない。

v81凍結通常HTMLと同一Native Coreを基準にPresentation patchだけを適用する。原画/4px/既存cadence/UI/673軌道/通常物理/打撃motor/移動を維持。原Charter承認HOLDと元計画の残件・旧FAILUNKNOWNを保持。userのAGENTS.md/旧dist等は対象外。
