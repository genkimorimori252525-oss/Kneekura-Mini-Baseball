## 2. 史料（並行して集める）
- MLB: 成績は Lahman（1871〜）、打球と体は Statcast（2015〜、バット計測は2023〜）、走力の目安 sprint speed、球場の寸法（年ごと）。
- NPB: OOTP_NPB_Historical（成績、database/ に能力の評価があれば使う）、球場（parks.csv）。
- KBO: 入手先を調べる（OOTP の KBO データ、公式記録など）。
- 時代の打ち方: 攻撃角、ダウンスイングの時代、反発係数の変化（飛ぶボール・統一球）、マウンドの高さ、球場の拡張など、リーグ環境の変化。
- 公開 repo に、データ本体・選手名と個人成績を入れない。非公開 repo `Kneekura-eatenBUGsHouse` の data/ に置く。

## 3. 換算（高速化の後）
- 打者: 三振→時間誤差、四球→選球眼、ISO と本塁打→パワー（バット速度）と攻撃角、BABIP→芯の誤差、盗塁と三塁打→走力。速度×時間誤差の相互作用を表にする。
- 投手: 三振・四球・被本塁打・BABIP から、球速・制球・球種・キレ。
- 守備: 守備率・刺殺補殺・UZR/OAA があれば、守備力・肩・捕球。
- 得能: 左右の成績差、得点圏、得意コース（Statcast のゾーン別、なければ推定しない）。
- すべて kbm-maker で書き、能力値は物差し（84＝MLB平均）で表す。

## 4. 再現の確認
リーグ・時代ごとに、全選手のリーグを回して、リーグ平均と選手ごとの成績を現実と比べる。合わない時代は環境（ボール、球場、ルール）を見直す。

## 年代の打ち方の手がかり（2026-11-05、史料部、非公開 repo の era/batted-ball-types/）
- Retrosheet の打球の種類は、2019年までは記録員の分類。2021年からは Statcast とほぼ同じになる。同じ打球での一致率は、2015〜19年が85〜87%、2021年が99.9%。
- 記録員には癖がある。ライナーは少なく、フライは多く付け、ポップはほぼ付けない。だから、時代をまたいで比べるときは、ゴロ・ライナー・（フライ＋ポップ）の3つで比べる。
- 2015〜19年の対応関係で、1988〜2014年を Statcast の分類と打球角に直した推定がある。それによると、打球角の平均は 10.8〜12.7° でほぼ一定、ゴロ率は 44〜47%。Statcast の実測は 2015年 10.9° → 2025年 13.3°、ゴロ率 46.5 → 42.1%。フライボール革命は 2015年以降の変化で、その前の27年はほぼ平ら、という推定よ。仮説で、過去の記録員の癖が同じだったと仮定している。
- 1987年以前は、分類の欠けが多い（分類が付いた打球が62〜78%）ので、割合は参考にしない。時代をまたぐ本塁打の比較は、打席あたりで行う。
- 年代の攻撃角の分布を合わせる段階で使う。標準のバット（d2eea4f）と速球の速さの年ごとの表（取得中）も、同じ段階で使う。
- 速球の速さ（史料部、era/fastball-velocity/）: 4シームの年平均は 2008年 92.1 → 2015年 93.1 → 2025年 94.5 mph（PITCHf/x は標本日、Statcast は全試合、等級 B〜A）。2002〜07年は BIS で約89〜90 と平ら（等級 C）。ただし、PITCHf/x とは尺度が違うのでつながない。2001年以前は、リーグ全体の公開された系列が無い（D）。年代の投手の球速の分布は、この系列から決め、その前の時代は打者の成績から逆に合わせる。
5. 空振りの出どころの作り（AMENDMENTS/2026-11-03-mlb-batting.md「空振りの出どころ」）: 今の試合の空振りは、ほぼ全部が「前の球を1球引いて、その場所へ引き寄せる」記憶の作りから出ていて、球の性質と関係しない。どの仕組みで置き換えるかは、ゲームの手触りにも関わる。ピッチング部の確かめが出たら、案を本人に示す。
