# デザインの接続棚卸し（S3、2026-11-02）

承認済みデザインのうち、本編で動いていないものの一覧。コードの読み取りで確認した。実機で全項目を操作したわけではない。

## 接続済み

詳細表示、手札の配置、詳細指示のせり上がり、振り方・打つ方向・走塁・コース・球種の指示、カード12枚（V0.11でセンター返し、引っ張り、流し打ち、敬遠を追加）、采配の打席単位化、名前の1行化、この試合の成績、打球データ（速度・角度）、スマホ上部の圧縮、試合前の遊び方・球場・諸元・試合の長さ・乱数、先発（TBDのみ）、打順と守備位置の編集、スコアボード連動、本塁打曲、実形状フェンス。

## 配線だけで済むもの（Coreに入口がある）

| 項目 | 足りないもの |
|---|---|
| 対戦データのタブ（コース別、ボールゾーン、打球方向） | タブと、シーズンパネルの集計の流用 |
| 「捕手側から」の表示条件 | 対戦データのタブと同時に切り替え |
| 成績表の打率以外の列（点、盗、死） | 履歴からの集計 |

## Coreの入力が要るもの

| 項目 | 足りないもの |
|---|---|
| 転がせ、犠牲フライ、ヒットエンドラン、スクイズ、盗塁のカード | 指示の入力 |
| クサイところ、打たせてとれ、緩急重視、1球はずせのカード | 指示の入力 |
| 牽制カード（1ターン3回） | 牽制の指示の入力。今はAI判断のみ |
| 詳細指示の狙う球・コース、追い込み後、初球、リード、組み立て、決め球、牽制の方針、守備 | 指示の入力 |
| セーフティバント | 送りバントと同じ `bunt` を送っている |
| 選手交代の確定 | 交代のAPI |

## データ待ち

| 項目 | 足りないもの |
|---|---|
| 代打、代走、投手交代、ベンチ、`右` `打 右` の表記 | 控え選手の名簿 |

## 本編に設定が無いもの

時間帯と屋根の切り替え。昼と屋根開閉の写真はデザイン側にあるが、本編に昼夜と屋根の設定が無い。
