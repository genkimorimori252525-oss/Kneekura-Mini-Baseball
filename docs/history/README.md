読み方の原則:

- **コードがある／候補を選んだ／実動作が成立した／9回を完走した**は別の証拠です。
- **旧ブラウザ、Native SQLite、ローカルHost＋共有Core**を混ぜません。
- **過去の報告**は当時のSourceについての記録です。新しいSourceのPASSにはなりません。HTMLの版名や入力ファイル数だけでも同一性は判定できません。
- 原因が未確定なら未確定と書きます。計測時間、例外、timeoutから推測した原因を確定事項にしません。
- テストの誤りと製品の誤りを分けます。テストがPASSしても画面の見やすさや現実の統計が証明されたとは扱いません。

## 今後追記する単位

新しい問題は `INCIDENTS.md` にIDを追加し、以下を一組として残してください。長いログは本文へ貼らず、元ファイルへリンクします。

```text
ID / 観測日 / 対象経路・Source・HTML SHA
症状と最小再現
最初の仮説と、その採否
確認できた根因（未確定なら未確定）
採用した修正と採用しなかった案
実行コマンド / receipt / 旧版の再現 / 新版の結果
変更しなかったもの / 残る限界 / 次の判定条件
```

元記録がローカル `outputs/`・`work/`・所有者のDBにしか存在しない場合は、その所在を区別します。本書から報告へのリンクがあっても、元DBや全巨大ログがGitHubへ公開されているという意味ではありません。今回のv43/v44の限定ブラウザ証拠は `docs/verification/releases/` へ同梱しました。
