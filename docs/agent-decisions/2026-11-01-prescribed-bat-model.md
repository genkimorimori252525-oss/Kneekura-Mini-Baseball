# 未捕球後のバット接触: 試合モデルの限定判断

2026-11-01。本人は依頼範囲内の通常判断を確認待ちなく行い、品質を落とさず実際に試合が進む版の実装を委任している。主担当は、既存Coreが連続したswing clipからバット姿勢を作り、clip中のバット放棄や反発後の球を意図して妨害する別操作を実装していないことを踏まえ、`prescribed_bat_attached_and_no_interference_v1` を**実測や人間の事実ではない明示的な試合モデル仮定**として限定採用する判断をした。本人がこのモデル名・個別条件を明示承認したと主張しない。

対象はclip期間内の標準swing、捕手がはじいた球のbat接触、空塁・非terminalで同tick競合が排除できる条件。2024年の全日本野球協会審判資料の事例7に照らす。打者bodyへ単に当たる場合は別であり無条件deadにしない。clip外、別操作、接触の同時性・保持状態をモデル上も決められない場合はHOLD。設定とversion付き保存に仮定をbindし、旧保存や他modeに黙って適用しない。原文・試作FAILは保持。

実験 `cabf2b5f3c3b4f64be8f4fca8e5c02d0` は固定seed/同Workerの3球記録と再開一致のみ。壁・地面を含む同tick、実UI、通常試合全般、未捕第3strike・四球・走者は未完。変更を直ちに一般採用しない。復旧は新policyのopt-inを無効にし、従来Hostを使う。
