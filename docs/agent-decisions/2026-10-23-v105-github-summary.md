### V105 身長・守備身体モデル・屈みの判断記録

2026-10-23。今回の直接依頼を、前回提示済みの身体モデル改善の実施指示として進め、追加指定の屈みも含めました。

- 身長、腰・肩・頭・目、肩からグラブへの到達域を共通モデルにしました。旧腰中心の最大距離を腕長としてそのまま転用する方法は採用せず、未設定時だけ身長等から解決します。
- 低い球への屈み、立ち直り、身体の向き直りを速度制限し、身体移動・手の連続可動域・捕球後の送球・中継・走塁予測に接続しました。捕球は実接触と保持で成立し、届かない球を結果だけで捕らせません。
- 7つの任意内部値をメーカー/守備練習で編集可能にし、初期値への復帰・保存/取消・JSON/AI編集・表示時刻の診断を接続しました。公開能力値・得能は独立です。
- 元PNG、配色、4px格子を維持し、屈み表示を追加。身体比率は暫定値、屈みの見た目は関節IKではないことを明記しています。

型検査、関連TypeScriptテストの56件群/53件群（重複あり）、身体運動4件、描画/視線26件を確認。実ChromeのPC幅1200px・スマホ幅390pxで深いRFフライ、SSゴロ、通常試合、メーカー、調整室を検証し、Sourceと表示カメラの目位置の誤差は0でした。入力・JSON・別19人・公開能力の保持も確認しました。
