## 変更対象と方針

- 新しい `LivePitchReleasePlanV168.ts` は、選択されたV78球の基礎物理入力を照合し、その球の名目spin/qだけを解決する。3選択の内部IDは実入力の識別に使い、ID自体で力/着点/打者結果を補正しない。
- `LivePitchV1.ts` に省略/null互換の1球操作 `pitchReleasePlanV168` を追加。基礎snapshotを上書きせず、名目spin/q→既存逆算/実行誤差→workload→同じSourceへ接続する。名目計画が実行後の乱数や未来軌道を使うことはない。
- planは球IDと元speed/spin/q/seamを持ち、元入力が変わったら拒否する。速度/物性/環境/seam係数をplanから変更させない。既存V78の有限spin/上限/unit q検証を使う。
- これは開発側の接続seamであり、利用者へspin/qを手入力させるUIではない。3段階の実技能/profile認定・選手JSONへの選択保存・Maker/Match接続・通常復帰UIは後続。未成立のV164候補を合格として流さない。
