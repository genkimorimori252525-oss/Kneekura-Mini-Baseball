# 白球・縫い目・ストライクゾーンの描画契約

更新日: 2026-09-21 JST  
状態: **ユーザー採用要件。改訂11の独立HTML試作で実装。本体の実試合への接続は未完了。**

## 改訂12の追記

ストライクゾーンを黄色 `#e0b541` に固定し、打席ごとの配球履歴を追加する。現在の白球は履歴の位置記号よりも優先する。[配球履歴の契約](2026-09-21-pitch-history-presentation-contract.md)を併せて適用する。以下の白球・縫い目・観測姿勢の原則は継続する。

## 決定

球は白い革と赤い縫い目で描く。球場・選手と同じ4px固定格子を使い、標準55msの観測時刻で表示する。既存文書の「黄色い球」はこの決定で置き換える。

ストライクゾーンのガイドと球が重なった部分は、球を優先する。線だけでなく、その黒い下地も球を消してはならない。これは説明用ガイドに対する優先度であり、球が手前のバット・グラブ・身体を透過する指定ではない。

縫い目は球の表面に固定する。球の向きが変われば縫い目も変わり、カメラを変えても同じ世界内の球を観測する。球種名・打球分類・結果・表示コマ番号で回転画像を選ばない。

## 入力の境界

描画器は位置、半径、絶対姿勢、カメラ投影を受け取る。絶対姿勢は、球のローカル座標をワールド座標へ移すクォータニオン `{x,y,z,w}`。入力のコピーを正規化し、元の観測値には書き込まない。

| 入力 | 意味・責任 |
| --- | --- |
| 観測時刻 | 再生側が選ぶ同一時刻。球・バット・姿勢の時刻をそろえる |
| `center` | 観測された球の中心。絵を合わせるために移動しない |
| `radius` | 入力側の球半径。縫い目を見せるために物理半径を変えない |
| `orientation` | その時刻の球の絶対姿勢。球の座標系からワールド座標系への回転 |
| `project` / `ray` | 同じカメラの投影と逆投影。視点変更で球の姿勢を変えない |

絶対時刻に対応する姿勢を使うため、停止、再開、逆送り、飛び越し、再生速度変更、視点変更によって回転位相がずれない。描画回数を積み上げて回さない。物理の更新、姿勢履歴の供給方法、回転軸の変更があっても、描画器はこの境界から新しい観測姿勢を読む。

### 現行Coreに足りない情報

確認した実装では `BallWorldState` にあるのは `position`、`velocity`、`spin`。球の初期姿勢と絶対姿勢履歴は含まれていない。回転ベクトルだけでは、縫い目の初期の向きは決まらない。

**この変更でCanonical型や物理は変更していない。** 上の姿勢入力はPresentationの受け取り口であり、既存Coreに追加済みという意味ではない。本体接続には、初期姿勢を含む正式な時刻サンプルの供給契約が別途必要。回転ベクトルの単位や軸対応を描画側で推測しない。

姿勢が欠落・不正なら、白球だけを描く。任意の初期位相や補間した姿勢を正史として埋めない。将来、正史姿勢が供給された場合は、その入力を渡すことで同じ描画処理が縫い目を表示する。

## 表面と距離

球面の見える位置をカメラの光線から求め、絶対姿勢の逆回転で球のローカル位置へ戻し、革か縫い目かを決める。背面の縫い目は透けない。白球の形・赤い縫い目・薄い陰影を最終的に4px格子へ落とす。

改訂11の縫い目は、球面上の閉じた曲線と短い縫い針跡を用いる表示用の形状である。実球の製造寸法、縫製本数、空力形状を確定するものではない。素材の見た目を変更しても位置・姿勢・物理へ影響を与えない。

| 投影直径（論理px） | 改訂11の細部 |
| --- | --- |
| 16未満 | 白球を優先し、縫い目を省略。遠景を赤い点にしない |
| 16以上56未満 | 赤い縫い目の曲線を表示 |
| 56以上 | 曲線と短い針跡を表示 |

粒の間隔を変えず、距離に応じて占める粒数を変える。格子以下の細部や速い回転は読めない場合がある。55ms間隔で高速回転を観測すると、見かけの回転が遅くなったり逆に見えたりする可能性がある。読みやすさのために正史の回転を遅くしない。

## 合成順序

1. 物体同士は奥行きで比較し、各格子点で見える物体を決める。
2. その結果、見えている球の点を保護する。
3. ゾーンの線と下地を描く際、保護した点に重なる部分を省く。
4. 名前枠も球の投影範囲を避ける。

改訂11は、線と8pxの黒い下地を含む範囲が球の光点を消さないように保護する。ゾーン全体の寸法・位置は変えず、重なる小区間だけを省く。

## 試作と検証

- `mini-baseball-ball-v11.html`: 白球の近景、3軸の回転、視点変更、ゾーンとの重なりを確認する単独見本。
- `mini-baseball-model-1-design-v1.html`: 既存球場試作にも同じ表面描画器と重なり規則を使用する改訂11。
- `observer-baseball-surface-v1.js`: 時計・試合結果・Coreへの書き込みを持たない表面描画器。

回転見本は、0.8回転/秒の明示した姿勢データを55ms間隔で用意したもの。球種や実試合の回転数を再現したものではない。球場内の既存の位置・バット両端・結果・時刻・球場寸法は改訂10から変更せず、別の姿勢見本を付帯させる。

検証対象は、球とゾーンの重なり、3次元の回転追従、逆送りの同一性、視点変更で姿勢が不変であること、姿勢欠落時の白球、遠景の白球、4px/55ms、元の観測入力の不変性。実試合との統合完了を意味しない。

採用済みのB1は顔なし・小顔・厚い身体。打撃は左右各4姿勢、投球はオーバー／アンダー／サイドの左右各6姿勢というデザイン決定を継続する。これらの採用画像は旧HTMLの人物描画へまだ組み込まれていない。旧人物試作の表示を採用デザインの実装完了と扱わない。
