# 心理・性格・感情マーク設計

更新日: 2026-09-17
状態: 将来実装用の採用済み設計。現時点では未実装。

## 1. 目的

選手の心理を「能力値とは別の大量な補正ゲージ」として追加しない。既存の能力、隠し能力、性格、経験、長期状態、試合状況を入力として一時的な感情反応を発生させ、その感情が十分に強く表面化した場合だけ、正史シミュレーションの行動・判断・能力発揮へ影響させる。

監督画面に表示する感情マークは演出ではない。マークが表示されている選手は、実際に通常時とは異なる能力発揮または判断傾向に入っている。

## 2. 恒久原則

### E-001: 通常は感情マークなし

- 選手の内部では小さな緊張、怒り、自信、恐怖などが常時揺れていてよい。
- ただし感情が通常範囲にある間は、能力値・判断・行動へ影響させない。
- 通常状態では感情マークを表示しない。
- 感情マークが頻繁に付くゲームにはしない。付いた瞬間自体が重要な情報・演出になる頻度を保つ。

### E-002: 感情マークが能力影響のゲートである

```text
内部感情が変化
    ↓
発火閾値未満
    ↓
能力・判断への影響 0
感情マークなし

内部感情が発火閾値を突破
    ↓
ActiveEmotion が成立
    ↓
感情マーク表示
    ↓
この時点から初めて能力発揮・判断へ影響
```

- 感情値が閾値未満である限り、内部値が 0.20 から 0.49 へ変化しても試合結果へ影響させない。
- `ActiveEmotion` が成立した瞬間から、定義された行動・判断・能力発揮の変化を適用する。
- `ActiveEmotion` が解除された後は、その感情による能力影響も終了する。
- 感情マークだけを表示して能力に影響しない「雰囲気演出」は禁止する。
- 能力だけ変化させてマークを隠すことも原則禁止する。監督が実際の異常状態を観測できることをゲーム性とする。

### E-003: 表示する感情マークは原則1個

内部では複数感情を同時に評価してよいが、監督画面に表示するのは最も強く表面化している `ActiveEmotion` 一つとする。

初期候補:

- 優越感
- やる気
- 恐怖
- 焦り
- 怒り

複数の候補が強い場合は、優先順位を固定するのではなく、その時点で実際の行動変化への寄与が最大の感情を表示する。

## 3. 感情は独立能力ではない

「怒り」「焦り」「恐怖」を選手の恒久能力値として一つずつ査定しない。

感情反応は次の既存・隠し要素の組み合わせから発生する。

```text
基礎能力・経験
+ 性格傾向
+ 長期状態
+ 直前までの出来事
+ 試合重要度
+ 個人的な意味
        ↓
Appraisal（本人がどう受け取ったか）
        ↓
EmotionPressure
        ↓
発火閾値を超えた場合のみ ActiveEmotion
```

性格・心理に関係する内部特性も増やしすぎない。必要な差は、既存の判断能力、経験、集中、精神安定性、自信、勝負欲、自己中心性、攻撃性など少数の軸から派生させる。

## 4. Appraisal: 同じ出来事でも反応を変える

試合イベントから直接「怒り +20」のように決めない。

```text
Event
  ↓
MatchImportance
PersonalStake
RecentHistory
Personality / Experience / Mental traits
ExpectedOutcome
  ↓
Appraisal
  ↓
EmotionPressure
```

例: 一死満塁で三振した新人

- 責任感が強く経験が浅い → 焦り・恐怖が発火しやすい
- 勝負欲と自信が強い → やる気が発火しやすい
- 自己中心性・攻撃性が強い → 怒りへ寄りやすい
- 精神安定性が非常に高い → 同じ失敗でもマークなしのまま終わりやすい

例: 初回・走者なしでの意図的な敬遠

- 「戦術価値が低い敬遠だから全員怒る」という固定ルールにはしない。
- 通常の戦術からどれだけ外れた行為か、本人の自信、相手への認識、最近の対戦履歴などを評価する。
- 優越感になる選手、怒りになる選手、特に反応しない選手が存在できる。

## 5. 試合重要度は自動算出する

ポストシーズン、国際大会、優勝決定直前、首位攻防などを試合ごとに手入力しない。

`MatchImportance` は大会・順位・残り試合・敗退条件などから自動計算する。

```text
MatchImportance = f(
  competitionStage,
  standingsLeverage,
  championshipLeverage,
  eliminationLeverage,
  matchupLeverage,
  personalStake
)
```

主な入力:

- レギュラーシーズンか、ポストシーズンか、国際大会か
- 決勝、準決勝、敗退決定戦など大会ステージ
- 勝敗による順位変動幅
- 優勝・突破・敗退が確定する可能性
- 残り試合数
- 直接対決による順位への影響
- 選手本人に関係する記録・復帰・因縁など、別システムから渡される個人的な重要度

重要度そのものは能力を直接変えない。重要試合ほど `EmotionPressure` が発火閾値へ到達しやすくなるだけである。

これにより、通常は極めて冷静な選手でも、WBC級の大舞台、優勝直前、敗退のかかった局面などでは初めて感情マークが付く可能性がある。

## 6. 発火・維持・解除

感情マークのちらつきを防ぐため、発火閾値と解除閾値を分離する。

```text
activationThreshold > sustainThreshold
```

- 発火には高い閾値を要求する。
- 一度発火した後は、少し感情値が下がっただけでは即座に消さない。
- 一定時間または一定イベント数、状態が落ち着いたことを確認して解除する。
- 新しい強い感情が発火した場合は、現在のマークとの行動影響を比較し、優勢な一つへ切り替える。

具体的な数値は実装時の大量試合検証で決める。現段階では固定値を設計書へ埋め込まない。

## 7. 能力への接続

感情発火後は「総合能力 -10」のような一括補正を優先しない。既存能力・意思決定のどの部分へ作用するかを明確にする。

例:

### 焦り

- スイング判断を確定する時刻が早まる
- 見切りに使える時間が短くなる
- 守備の再計画時刻が遅れる場合がある
- 走塁の帰塁・進塁判断閾値が変化する

### 怒り

- 強いスイングや強い送球を選びやすくなる
- 慎重な選択の閾値が下がる場合がある
- 性格によってはパワー発揮が上がる一方、選球・精度が悪化し得る

### 恐怖

- リスクの高い選択を避けやすくなる
- 見逃し・消極性・帰塁優先などに影響し得る
- 高い精神安定性や経験により影響が小さくなる

### 優越感

- 自信・積極性が高まる
- 性格によっては余裕を取りすぎ、送球開始・帰塁開始などが遅れることがある

### やる気

- 集中・積極性・実行の再現性が通常より高い側へ寄る場合がある
- ただし万能な能力上昇にはしない。どの能力が発揮されるかは選手の元能力と性格に依存する

同じ感情マークでも、全選手に同じ補正を適用しない。

## 8. 性格と凡ミス・判断ミス

性格は「エラー率 +5%」のような直接乱数補正ではなく、正史時間軸の意思決定や実行へ接続する。

例: 余裕を見せやすい選手

```text
ActiveEmotion = 優越感
+ 自信過剰傾向
        ↓
捕球後に余裕を取る
        ↓
ThrowIntent 発行が 0.x 秒遅れる
        ↓
実際の送球到達と走者到達の時間差でアウト/セーフが決まる
```

例: 牽制死

```text
走塁能力
+ 帰塁能力
+ 積極性
+ 自信
+ ActiveEmotion
+ 投手の牽制能力
        ↓
リード距離・帰塁開始時刻
        ↓
正史時間で牽制アウト判定
```

## 9. 監督にとっての感情マーク

感情マークは監督の判断材料である。

- マークなし = 少なくとも感情による能力・判断補正は現在発生していない。
- マークあり = その感情が実際に試合挙動へ影響している。
- マークから正確な内部数値や補正量までは表示しない。
- 冷静な選手に珍しくマークが付くこと自体が重要な情報になる。
- マークは選手アイコン/写真へ一つだけ重ねて表示する想定とする。

以前の「心理状態をUIへ直接表示しない」という一般原則に対する唯一の例外として、`ActiveEmotion` の感情マークを認める。内部感情値、発火閾値、補正量、詳細な推定値は引き続き非公開とする。

## 10. 長期状態との境界

次のものは感情そのものではない。

- スランプ
- 疲労
- 移籍欲求
- チームへの不満
- 個人成績への執着
- 監督との関係
- 新人・ベテランなどの経験状態

これらは長期状態として保持し、Appraisal と発火閾値に影響する。長期状態が直接「怒りマーク」を付けるのではなく、その選手が試合中の出来事にどう反応しやすいかを変える。

## 11. 乱闘・集団感情への拡張

乱闘などの特殊イベントは将来の `IncidentSystem` で扱う。

- 一人の怒りをチーム全員へ直接コピーしない。
- 発生した事件を各選手が個別に Appraisal する。
- 攻撃性、仲間意識、対戦相手との関係、試合重要度などにより反応を変える。
- その結果として複数選手へ異なる ActiveEmotion が発生し得る。

試合規則上の退場・警告等が必要な場合は `RuleProfile` と接続し、感情システム自身が競技規則を決定しない。

## 12. 再現性

感情発火は正史シミュレーションの一部である。

- 同じ入力、同じ選手状態、同じ大会状態、同じシードなら、感情発火も再現できること。
- リプレイで感情を再抽選しない。
- `EmotionActivated` / `EmotionChanged` / `EmotionCleared` のような時刻付きイベントとして保存できる契約を将来持つ。
- Natural Baseball では、同じイベントから表情・仕草・アニメーションを追加してよいが、3D側から感情状態を変更しない。

## 13. 必須テスト方針（将来）

実装時には最低限以下を固定する。

- 閾値未満の内部感情変化では能力・判断結果が一切変わらない
- マーク発火と同じ時点から初めて能力・判断への影響が始まる
- マーク解除後は感情補正が残留しない
- 同一選手でも通常戦と高重要度試合で発火しやすさが変わる
- 精神安定性の高い選手は通常マークが付きにくいが、極端な重要局面では発火可能
- 同じイベントでも性格・経験が異なる選手で別の感情または無反応になり得る
- 表示される感情マークは原則一つ
- 描画OFFでも感情発火と試合結果が同一
- リプレイで感情を再抽選しない

## 14. 現時点の結論

感情システムは「常時能力を揺らす隠し乱数」にはしない。

**通常はマークなし・能力影響なし。感情が発火閾値を超えて `ActiveEmotion` になり、監督画面へ感情マークが表示された時に初めて能力・判断へ影響する。**

試合重要度は手動設定ではなく大会・順位・優勝/敗退条件などから自動算出し、大舞台ほど発火しやすい。ただし重要度そのものが能力を直接変えることはない。
