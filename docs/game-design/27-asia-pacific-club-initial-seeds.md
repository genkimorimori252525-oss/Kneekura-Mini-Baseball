## Interpretation

- 数値はCareer開始時のSeedであり、Pennant開始後は固定しない。
- Rankは `S 90+` / `A 80–89` / `B 70–79` / `C 60–69` / `D 50–59` / `E 40–49`。
- Finance / Popularity / Development / Scouting / VenueはMatch Coreへ直接Buffしない。
- Football-derived ClubのVenueはFootball stadiumそのものではなく、そのClubの市場・施設規模をBaseball Worldの初期野球Venueへ変換したSeed。
